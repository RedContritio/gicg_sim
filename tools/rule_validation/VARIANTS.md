# 随机规则训练（2026-09-14）

目标仍是五原生角色、23牌、3v3随机合法30张下显著优于D1、稳定胜于D2。变体仅作为训练分布扩展，不替代正式规则胜率。

## 当前范围

`configs/rule_validation/native_variants.toml` 明确列出30个参数点：15个技能的指定元素骰子费用，以及15个直接伤害/治疗参数。费用仅改变指定元素数量，任意骰子、能量、元素类型不变；迪卢克第三次战技保持基础值+2。召唤物伤害、持续回合、技能禁用尚未纳入第一阶段。

每局从参战角色的参数中随机选1–2项，生成独立临时数据目录，整局固定、双方共享同一规则。正式池不修改。补丁使用公共 `patches.apply`，文本不再唯一匹配时明确失败。

训练每四局按原生/变体/变体/原生分配，兼顾双方席位；训练环境各占一半，决策行数未必各占一半。效果训练值1/3/5/7、费用1/3/5；评估变体效果值2/4/6/8、费用2/4/6，均排除与原值相同的无效修改。这是“未见修改值”划分，原生环境仍可能包含这些数字，不能声称所有数值首次出现。

引擎执行修改后的DSL，模型观察同一环境的IR、规则图和合法支付。D2在每局实际变体中重新计算标签。BC及RL逐局记录参数、种子、补丁和数据SHA；训练记录目录中的 `episodes.json` 可复核。评估的两席位和两布局共享同一场景变体。

## 一个脚本运行至结束

先同步相关源码至56；这是工具层变更，当前引擎无需重建。仓库根目录运行：

```bash
.venv/bin/python -m tools.experiments.semantic_training.variant_pipeline configs/dmc/native_starter.toml artifacts/native_variants_20260914
```

入口按训练配置转发56，单次远端调用依次完成：

1. 随机初始化，512局混合规则D2示范，4000次GPU更新。
2. 原生D1/D2各220开发局，以及220局未见变体D2评估。
3. 4轮RL，每轮256局混合规则，D2对手；状态基线、温度0.5，每轮原生D2开发选模。
4. 保留BC候选，开发同分优先较早检查点；评估选中模型的原生D1/D2及未见变体表现。

训练seed93900、RL93910、原生开发93100、变体开发93990。所有均为开发用途，不使用保留的三种子最终验收面板。预算增大与规则随机化同时发生，因此不是等预算消融。

脚本不轮询训练文件，而是等待各阶段函数返回。输出 `console.log`、原子更新的 `pipeline.json`，正常结束或异常均写 `completion.json`；异常停止后续阶段并返回非零。远端断电/进程被强杀可能来不及写完成文件，不能把文件缺失当作成功或自动重启依据。

当前会话没有暴露独立外部事件唤醒接口。该脚本能独立完成训练和评估、一次返回结果；这不等于已配置关闭会话后的自动唤醒。不要再为普通进度反复发起模型轮询；需要读结果时优先读取一次完成事件/进程退出状态。
