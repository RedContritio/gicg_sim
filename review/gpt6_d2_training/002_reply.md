# 结论：下一步选有预算上限的 V 诊断，M 作为唯一备选

**我建议下一步主线选 V，但只批准“冻结策略的 value 表示与决策相关性检验”，不批准直接扩大 value-bootstrap 教师，更不批准恢复当前 MCTS。**

理由不是 value 理论上优于 DMC，而是：你已经付出了大量真实终局续局成本，现在可以用较低的新增成本，检验这些数据能否支持一个有用的价值估计器。这个检验不需要改变策略，因此失败时也不会再次损坏 RL16。

**唯一备选是 M：从原 SemanticQNet 出发的 native DMC。R 暂停作为独立投入方向。** 如果 V 没有通过本轮限定预算内的检验，就转向 M，而不是继续为教师寻找更多样本。

同时需要修订第一轮建议中的一个过强条件：

> **C 教师通过，应当是“蒸馏该教师”的前提，不应成为“允许 native DMC 学习”的前提。**
>
> 原生 Monte-Carlo 价值学习不需要先获得一个独立合格的重掷教师。DouZero 使用的也是执行轨迹回报回归与策略改进，而不是先要求搜索教师逐阶段获得资格。它与终局 policy-gradient 也不是同一种更新方法。:chatgpt-content-reference{index="0"}

当前能确认的是**发现了足以解释部分历史实验失效的实现问题，并阻止了一次没有收益证据的蒸馏**。尚不能确认重掷能力提升、旧模型能力恢复或稳定超过 D2，三者都还没有取得新的通过证据。

### 三个需要立即修正的解读

#### 1. “随机流错位”不等于“终局差值必然有偏”

只要两个分支各自仍服从正确的游戏随机分布：

\[
\mathbb E[Z_a-Z_c]
=
\mathbb E[Z_a]-\mathbb E[Z_c]
\]

这个恒等式与是否使用共同随机数无关。

不同重掷数量导致后续 RNG 错位，主要会破坏原本希望得到的正相关，可能使方差变大。真正使标签有偏的是：**分支边际分布错误、条件后验错误、复用随机数造成分支内部不应有的相关，或者根据结果筛选样本。**

因此，旧 generic reroll 实验需要隔离的主要理由是宏动作契约不一致；RNG 错位是另一个问题，不能将两者混成“所有旧终局样本都无效”。

#### 2. 两个根的正态 95% CI 不具备总体推断资格

不对齐设置中的两个根均值为 \(+0.03125,-0.03125\)，你报告的区间正好约等于：

\[
0\pm1.96\times0.03125
\]

这里用于估计根间变异的独立单位只有 **2 个**。即使暂时套用正态总体下的 Student-\(t\) 方法，临界值也应是 \(t_{0.975,1}\approx12.706\)，得到约：

\[
[-0.397,\,+0.397]
\]

这不是推荐用这个巨大区间取代原区间，而是说明：**当前两个根不足以估计总体根间异质性，bootstrap 也不能凭空补出这种信息。**

这组结果可以报告每个固定根的条件比较，并为它们分别计算续局层面的区间。不能把两个根均值之间很小的差异解释成总体估计很精确。

另外，若目标是整个四根选择规则的收益，两个选择 current 的根应以**策略差值恰为零**纳入，而不是只报告“触发改变动作的根”。后者估计的是条件收益，需要同时报告触发率。

#### 3. 收益单位很可能还混用了 signed outcome 与得分概率

你给出的 384 对中，正差 40、负差 42、零差 302。若非零差对应无平局条件下的胜负翻转，则：

\[
\Delta_{\text{signed}}
=
\frac{2(40-42)}{384}
=-0.0104167
\]

这恰好对应报告的 `-0.0104`。但得分概率差是：

\[
\Delta_{\text{score}}
=
\frac{40-42}{384}
=-0.0052083
\]

也就是约 **−0.521 个百分点，而不是 −1.04 个百分点**。

应从原始 winner/draw 记录重新生成所有统计量，明确字段是 `signed_return_delta` 还是 `score_delta_pp`。若存在平局，正负差的幅度不一定相同，不能只根据正负计数还原均值。

## 二、value 编码问题：哪些结论受污染，哪些不受污染

### 首先，`win probability` 这个名字需要改准

在胜 \(1\)、负 \(0\)、平 \(0.5\) 的编码下：

\[
p_{\text{score}}
=
P(\text{win})+\frac12P(\text{draw})
\]

它是**期望得分**，存在平局时不等于纯胜率。于是：

\[
v_{\text{signed}}=2p_{\text{score}}-1
\]

是正确转换，但正式标准究竟要求纯胜率下界超过 50%，还是期望得分下界超过 50%，必须预先写明。不能在训练与验收之间悄悄换指标。

### 线性层转换正确，但不能只检查最后一层

若输出确实是未经过其他非线性变换的：

\[
v_p=w_p^\top h+b_p
\]

则：

\[
w_s=2w_p,\qquad b_s=2b_p-1
\]

可以精确转换。还要检查激活、clipping、归一化、终局覆盖值和默认叶值是否在别处执行了第二次转换。**模型加载两次不能转换两次。**

建议 checkpoint 至少同时记录：

`value_encoding`、`value_perspective`、`return_definition`、`environment_version`、`continuation_policy_hash`、`opponent_hash`、`observation_schema`。

仅记录 encoding，仍然无法识别“P0 的 signed 胜负”和“当前行动玩家的 signed 胜负”。

### 污染范围与重跑要求

| 实验或产物 | 处理 |
|---|---|
| 原 native RL16 直接 argmax 的胜负记录 | 保留，不因 value 工具错误自动失效 |
| 完整宏动作、纯终局续局产生的原始 winner/draw | 保留；重新统一编码和统计，不必因此重跑 |
| 上述教师的候选仅由真实终局回报选择 | 编码统一且正向仿射转换一致时，动作排序不变；通常只需重算报告 |
| 候选筛选、停止规则或标签权重用过含义错误的 value | 该阶段需要重做，不能只修最终报告 |
| value MSE、bias、校准图 | 用确认编码后的预测和标签重新计算 |
| 由错误 value 构造 bootstrap target 的训练 | 从最后一个干净 checkpoint 重启相应阶段 |
| 当前有随机节点合并问题的 MCTS 实验 | 不值得仅修尺度后原样重跑；先修搜索契约 |
| 转换后的 AZ 相对“RL16”的比较 | 重新标识模型；需要比较原 RL16 时，补做原模型对照 |

### policy-gradient 的污染需要单独判断

一个重要细节是：在正确的 on-policy、停止梯度、与动作无关的 baseline 条件下，即使 baseline 数值尺度不对，也有：

\[
\mathbb E_{a\sim\pi}
[\nabla\log\pi(a\mid s)b(s)]=0
\]

因此，**baseline 尺度错误不必然改变期望策略梯度，但可能严重增加方差。**

反过来，若动作来自 argmax/其他行为策略，却按另一个 softmax 策略计算未经修正的梯度；或者先用同一批数据拟合 baseline，再用它生成该批梯度；或者 baseline 实际依赖动作，就不能套用上述结论。相关研究已经展示，同批拟合、归一化和实现细节足以改变估计器的偏差性质。:chatgpt-content-reference{index="1"}

所以，四个单步更新应做一次**估计器契约审计**，而不是直接宣布“value 编码解释了它们全部失败”。

## 三、V 值得做，但应检验正确的目标

### 1. V 不是“学习一个通用的局面好坏分”

本轮应明确学习：

\[
V^{\pi_0,\rho}(I')
=
\mathbb E[Z\mid I',\text{后续己方 }\pi_0,\text{对手 }\rho]
\]

其中 \(\pi_0\) 是原 native RL16 的完整续局策略，**包括未来回合重掷**；\(\rho\) 是冻结的 D2。

若训练数据的后续策略包含探索、不同历史 checkpoint 或不同重掷模块，目标就发生了变化。不能把它们无标识混合后仍称为 \(V^{\text{RL16},D2}\)。

对重掷宏动作的评分应为：

\[
\widehat Q(I,a)
=
\frac1M\sum_{j=1}^{M}\widehat V(I'_{a,j})
\]

\(I'_{a,j}\) 必须来自正确的条件分布，并位于明确一致的边界：例如双方重掷与 round-start effects 全部完成后的决策状态。

**先对随机结果求期望，再选动作。不能每个隐藏世界分别选最佳动作后再平均。**

### 2. “冻结 backbone”是诊断手段，不是表达能力保证

RL16 的表示可能擅长区分当前动作，却没有保留预测长期绝对回报所需的信息；也可能只是 value 读取了错误的池化结果。

我建议同一份固定数据只比较三个小探针：

| 探针 | 结构 | 回答的问题 |
|---|---|---|
| V-linear | 冻结表示＋线性回归 | 现有表示中是否已有线性可读取的价值信号？ |
| V-MLP | 同一冻结表示＋一个 64 宽隐藏层 | 只是线性读出不足，还是表示本身不足？ |
| V-observation | 同一表示＋小型可训练分支，读取原始可见骰子、counter、阶段及规则 tokens | 旧表示是否丢掉了关键可观察信息？ |

第三个分支不需要人工骰子评分，也不进入普通策略路径。

**V-linear 失败而 V-MLP 成功，不能说 backbone 不够；只有补充原始观察才成功，才更支持表示或池化存在信息损失。** 三者都失败，也不能立即说数据不足：先在少量标签可靠的样本上检查可拟合性，再比较按独立来源拆分的学习曲线。

另外，冻结必须包含运行状态：backbone 应处于正确的 `eval` 模式，不能通过 BatchNorm 统计量、dropout、共享参数或 optimizer weight decay 改动普通策略。固定普通面板上的输出应保持一致。

### 3. 不要要求模型把随机终局“预测正确”

对于单条胜负标签 \(Y\)，平方误差包含不可消除的随机性。应比较：

- 相对阶段条件常数基线的误差下降；
- 对重复终局均值的预测误差；
- 同根候选差值的预测能力。

**训练集终局分类准确率不高，不足以说明表示差；全局 MSE 很低，也不足以说明候选排序好。**

尤其要避免“跨根排序准确”：把明显优势局排在明显劣势局之前，与在同一个根中分清两个重掷方案，难度完全不同。

## 四、value 的 go / no-go 应围绕决策，而不是单一 MSE

下面是我建议的**本轮开发门槛**，不是文献中的通用标准。全部使用 \([0,1]\) 的期望得分尺度；signed 尺度数值相应乘二。

### 统计单位必须分层说清

**transition** 是一次训练观测，不是独立证据数量。  
**candidate** 是同根内的比较对象，不是独立场景。  
**root** 才是本轮候选决策评估的基本单位；若多个根来自同一来源对局或同一场景族，应继续向上聚类。

同一根的所有候选、续局和后继状态必须在同一个训练/验证分区中。来源于同一根的数千条续局，不能随机切成训练与测试后宣布泛化成功。

### 建议门槛

| 指标 | 建议用途和门槛 | 何时停止 |
|---|---|---|
| 编码与视角 | 精确契约测试全部通过 | 任一未解释失败，停止后续实验 |
| 相对常数基线的 MSE 改善 | 独立来源上应有正向改善；作为预测能力筛查 | 三个探针均无稳定改善，停止扩大 value 数据生成 |
| 整体校准 bias | 初筛希望点估计绝对值 ≤3pp；区间若仍很宽，只能记未决 | 明显、可复现的系统偏差先修目标/分布，不靠更多候选掩盖 |
| 分箱校准 | 先只画 4 个预固定箱，报告每箱独立根数；用于定位阶段性失真 | 不以少数根形成的“漂亮校准图”授予资格 |
| 同根候选排序 | 对可辨别比较，根等权准确率目标 ≥60%，探索性区间下界高于 50% | 与随机排序无可分辨差异，停止作为候选筛选器 |
| 相对 current 的方向 | 报告正负两类的 balanced accuracy，以及“预测改善”的 precision；初筛分别目标 ≥60%、≥65% | 只会预测“都不如 current”，却靠类别不平衡获得高准确率，不通过 |
| 最终选择收益 | 冻结选择规则后，独立真实终局验证的根等权 95% CI 下界 >0 | 上界 ≤0 则 no-go；跨零且预算耗尽则暂停，不扩训 |

这些代理指标不能被误用：

**校准不是候选排序的必要条件。** 同根所有候选共同偏移 10pp，可以保持决策完全正确。

**排序率不是 teacher gain 的充分条件。** 在很多差距极小的对比上排对、却在少数重要对比上排错，整体收益仍可能为负。

因此，最终准入仍以真实终局收益为准；建议同时设置一个工程意义门槛，例如点估计至少改善 **2pp**，避免为统计上微小、计算上昂贵的收益建设大型教师系统。

对“可辨别比较”，不要直接拿 8 次续局的均值正负当真值。应结合其不确定性；本轮可以重点考察真实差值量级约 5pp 以上的比较。若预算内连足够数量的可辨别根都得不到，结论是**这个面板不适合低成本判断排序能力**，不是模型已经被证明不会排序。

另外，**不需要每一个根都 individually qualified，才允许一个总体有正收益的教师通过。** 逐根显著性会把小预算变成几乎不可能通过的门槛。

## 五、大量零差：先区分“耦合成功”和“真的没有可学优势”

在无平局、得分差 \(D\in\{-1,0,1\}\) 的情况下，定义：

\[
q=P(D\ne0),\qquad
\theta=P(D=1\mid D\ne0)
\]

则：

\[
\mathbb E[D]=q(2\theta-1)
\]

你的计数对应：

\[
\hat q=\frac{82}{384}\approx21.35\%,\qquad
\hat\theta=\frac{40}{82}\approx48.78\%
\]

因此，这批数据不只是“太多零导致学不到”：**在发生胜负差异的样本中，当前候选也没有显示方向优势。**

而且零差包含不同原因：两个动作续局确实接近、当前随机世界对动作不敏感、配对很好地消除了共同随机影响，或者多个正负效应在根均值上相互抵消。不能把零差统一解释成真实价值相等。

### 预算分配建议

**候选发现阶段**可以使用顺序比较、方差自适应和淘汰明显劣候选；**最终验证阶段**优先保留固定样本与独立 seed，减少统计复杂度。

仅做了 8 次配对且全部零差，并不能证明效应很小：在独立配对假设下，零次 discordance 对其发生概率给出的单侧 95% 上界仍约为 **31.2%**。

所以不要把“8 次全零”的根永久删掉，也不要只给已经出现正差的根追加预算。适合的分配依据是估计方差、决策边界附近的不确定性和潜在收益上界，而不是当前均值是否好看。

如果反复查看区间并据此继续或停止，应使用有效的顺序推断或预先固定检查点，不能每次都套普通固定样本 95% CI。置信序列可以支持这种可选停止，但区间通常更宽，并不免费提升检验能力。:chatgpt-content-reference{index="2"}

### value 可以作为控制变量，不必直接替代真实终局

V 通过预测检验后，可以考虑：

\[
\widehat\Delta
=
\frac1M\sum_{j=1}^M m(U'_j)
+
\frac1N\sum_{i=1}^N\left[D_i-m(U_i)\right]
\]

这里 \(m(U)\) 是冻结 value 对某个随机情境下候选差值的预测，第一项用便宜的大批量模拟估计其均值，第二项用真实终局纠正残差。

在抽样分布正确、两项均值估计有效且 \(m\) 预先冻结的条件下，预测偏差可以在期望上抵消。这比“直接把 value 当真值”更容易控制偏差，但能否省计算取决于残差方差及额外推理成本。控制变量的基本原理正是保留原期望、利用相关性降低方差。:chatgpt-content-reference{index="3"}

**本轮先不实现完整控制变量系统。** 先检查冻结 value 能否明显降低真实配对差值的残差方差；否则这只是增加另一层复杂度。

## 六、CRN 应按语义事件耦合，而不只拆三个全局随机流

按骰子、抽牌、其他事件拆流是有用的第一步，但同一流内部仍可能错位。例如一张牌额外制造一次骰子随机事件，后续所有骰子调用仍可能发生偏移。

建议采用类似下面的寻址方式：

```text
random_value = RNG(
    experiment_seed,
    root_id,
    replicate_id,
    subsystem,
    round,
    player,
    semantic_event,
    occurrence,
    item_index
)
```

基于计数器的 RNG 可以直接把随机数实现成 key/counter 的无状态函数，适合这种显式寻址；但语义键怎样设计，仍需要由模拟器保证。:chatgpt-content-reference{index="4"}

### 针对重掷的具体做法

重掷前为原始骰子建立稳定槽位。候选动作只决定哪些槽位重掷；同一槽位、同一轮、同一次重掷使用相同随机变量。未使用的随机变量不影响未来事件。

必须保证同一分支内部不同随机事件不错误复用随机值。对于分支特有的事件，使用独立的事件标识，不要为了“对齐”强行让不同性质的事件共用随机结果。

抽牌则优先在根处根据正确条件分布生成完整剩余顺序，后续按该分支的合法抽取协议使用；洗牌、插牌、生成卡牌另有事件标识。策略探索与随机 tie-break 也应使用独立的随机命名空间。

### 最少要有四类测试

| 测试 | 应满足什么 |
|---|---|
| current 对 current | 相同隐藏世界、相同随机情境、确定性策略下，逐轨迹一致 |
| 候选枚举顺序置换 | 改变候选遍历顺序不应改变各候选对应结果 |
| 单分支边际分布 | 耦合版与独立模拟版都符合规则概率 |
| 方差比较 | 在预先固定候选上比较配对方差；不能根据均值更好看选择耦合方案 |

**CRN 的目标是改善相关性，不是让两个不同动作经历“字面相同的未来”。** 正确边际分布优先于最大程度对齐。

## 七、先手根仍有价值，但“先手”不是后验正确性的保证

先手重掷可以作为一个受限研究子问题，没必要因为后手模型未完成就停止一切诊断。

但必须补充一个更普遍的风险：

> **不仅后手骰面需要条件后验，对手手牌与牌库划分也可能需要根据已发生的行为更新。**

如果对手此前见牌后选择了动作、弃牌或其他操作，那么仅保留牌数和公开剩余牌表、再均匀重分手牌与牌库，通常不等于正确的条件分布。类似地，己方牌库经历过查看、排序或特殊插牌之后，也不能无条件重洗。隐信息搜索中的价值依赖信息状态及相应信念，而不仅是可见棋盘。:chatgpt-content-reference{index="5"}

所以：

**允许继续的是：采样分布已经明确验证的先手根诊断。**  
**暂停的是：把它未经验证地扩展到所有回合、所有先后手的通用重掷教师。**

对后手，较稳妥的模拟方法是先从合法的前置隐藏分布出发，让冻结 D2 执行其真实重掷过程，再根据学习方实际可观察到的事件进行条件化，而不是直接均匀生成一组“已经重掷后的骰子”。

V 和 M 的自然对局数据可以先正常收集：从真实合法初始状态前向运行，会产生实际策略诱导的数据分布，不必为了开始学习就先解决通用反事实后验采样器。

## 八、M 可以独立启动；31 条 ordinary rows 更像是需要审计的数据管线

### native DMC 应保持它本来的目标

本轮备选 M 应使用：

\[
L_Q
=
\mathbb E\left[
\left(Q_\theta(I,a_{\rm executed})-Z\right)^2
\right]
\]

而不是把 Q softmax 化后继续称为 DMC、实际执行终局 policy-gradient，也不是只保留 paired preference 非零的样本。Monte-Carlo 回报回归能够直接利用执行轨迹，不需要 bootstrap 或搜索教师。:chatgpt-content-reference{index="6"}

第一阶段仍可冻结普通路径，只训练新的完整重掷评分分支。区别是这个分支通过**真实执行与终局回报**学习，而不是等待反事实教师合格。

采集时允许有明确记录的宏动作探索，不使用人工骰子价值。重掷训练单位应为一次完整宏动作；不要因为运行时分八种颜色提交，就把一个决策复制成八个同权训练样本。

### 防止稀少根被淹没，也防止反复拟合同一批根

训练新分支时可以主要采样重掷；进入联合 DMC 后再使用 ordinary/reroll 分层。关键是先按来源对局或根抽样，再抽该根的样本，而不是让拥有更多续局或内部原语的根获得更多权重。

初始控制数据复用，例如每批新增数据最多做少量完整遍历，不继续采用“每局固定 4×256 次抽样”作为默认合理值。相同根重复 100 次，不等于获得了 100 个新的训练局面。

### 对 31 条 rows，要先补齐一张“流失表”

至少记录：

`访问决策数 → 可比较根数 → current/alternative 真正不同数 → 成功完成续局数 → 去重后根数 → 有 discordance 数 → 最终训练 rows 数`

然后逐步解释每个过滤条件。

特别检查那 17 条权重为 0.25 的 rows：

- 若权重来自明确的采样概率或可靠性模型，需要写出其估计目标。
- 若只是“没有观测到差异，但仍沿某个方向做弱偏好更新”，这就是在制造没有证据的方向标签。
- 若零差样本被全部删除，则训练集已经按结果选择，目标分布发生变化。

**只有 31 条有效 rows，不足以说明普通动作没有改进机会。它首先说明当前“有效”的定义可能过于狭窄。** 对 Q 回归而言，很多被偏好管线删掉的终局轨迹仍然是可用数据。

## 九、下一组最小实验：先零新增续局筛查，再有条件花预算

我建议只开展下面这一组，不同时开 V、M、R 三个训练臂。

### 实验配置与预算

| 步骤 | 配置 | 新增成本与停止条件 |
|---|---|---|
| **S0：契约与重算** | 修复 encoding/视角；从 winner 重算统计；宏动作与逐色协议等价测试；current/current、枚举顺序测试 | 不做长训练；任一关键失败就停 |
| **S1：离线 V 探针** | 优先复用审计通过的新规则轨迹；最多取 64 个独立来源组，48 训练、16 开发；同源续局不得跨区 | 不为追求更多 transition 重跑大量对局；若原数据未保存必要观察，最多补 64 局 |
| **S1 模型** | V-linear、V-MLP、V-observation；每个最多两个 head 初始化；缓存冻结特征；每个最多约 1000 次小批更新 | 由开发集预先选定一个主探针；其他仅用于诊断 |
| **S2：新根检验** | 24 个未参与拟合和选模的新先手根；每根 current＋两个预固定方式产生的合法候选 | 不挑“容易出现 non-current leader”的根 |
| **S2 标签** | 每候选先 8 次真实终局续局，共 576 条；无明显失败时按预定计划补到 16 次，总计最多 1152 条 | 8 次阶段只允许故障/无望停止，不宣布成功；最终只正式判断一次 |
| **总预算上限** | 本轮新增采集累计最多约 150,000 环境步或 75,000 次学习方前向，任一先到即停 | 包括补充自然对局和根生成；不足预定样本则记未决，不能把截断当终局 |

这些是预算上限，不是必须全部用完。**S1 没有显示价值信号时，S2 不启动。**

两个候选可以采用“均匀合法宏动作”和“随机单颗骰子选择变化的合法邻域动作”，不按元素价值筛选。这样同时覆盖较远和较近的选择差异，而不引入 D2 规则。

对候选的 value 评分可以使用独立的短模拟随机样本，完成宏动作后继状态生成并批量前向。**这些样本与真实终局验证 seed 分离。** 主探针与选择规则必须在看到 S2 的终局标签前固定；不能根据 S2 比出三个探针中的赢家，再拿同一面板证明赢家合格。

如果当前只有开局先手根的条件分布被验证，那这 24 根就只研究该范围，不为扩覆盖引入未验证的中局后验。

### 本轮 go / no-go

**进入 S2：** 至少一个冻结探针在独立来源开发集上表现出可靠的预测信号，且目标、视角、宏动作协议无错误。

**允许继续 V→候选筛选研究：** 同根比较存在可辨别信号，且预固定选择规则在独立终局上的总体收益为正、95% 区间下界高于零。没有达到这一点，不训练大规模 reroll adapter。

**停止扩大 V：** 三种探针均无有用信号；或仅能跨根分胜负、不能区分同根候选；或筛选后的真实收益没有通过，而本轮预算已耗尽。

区间跨零应分成两种业务结论：有证据表明不值得继续时 no-go；信息仍不足但成本过高时暂停。**都不意味着继续自动翻倍样本。**

本轮的独立根面板是开发验证，不是最终战胜 D2 的测试集。之后用它改变过配方，就不能再作为最终独立验收。少量训练运行与反复选模需要明确区分，不能用一个区间名称掩盖这些层次。:chatgpt-content-reference{index="7"}

## 十、仍可能使整个解释失效的高严重性风险

下面这些优先级高于继续调学习率或增加续局。

| 严重性 | 风险 | 检查方式 |
|---|---|---|
| **最高** | 完整 macro 与运行时逐色提交并不等价 | 检查是否边提交边看到新骰面、能否再次选择新生成骰子、current 宏动作能否重现原策略；验证完整轨迹而不只最终骰数 |
| **最高** | 后验采样丢掉历史证据 | 构造小牌库可精确枚举案例，比较采样频率与条件分布；尤其检查手牌选择行为和已经完成的重掷 |
| **最高** | 模拟器真值泄漏到决策 | 固定信息状态、替换隐藏世界，网络输入与非特权选择逻辑应不变；明确区分模拟器执行权限和策略观察权限 |
| **最高** | 超时、非法动作、引擎异常被记为输或平 | 单独报告这些事件；不能让动作更长的分支因预算截断系统性受罚 |
| **高** | 两分支的续局策略或阶段边界不同 | 每条样本记录策略 hash、阶段、完整宏动作签名；不要一个分支用 native、另一个用 AZ/探索策略 |
| **高** | 反事实分支沿用事实分支终局标签 | 核对每个 outcome 与实际执行分支的一一对应 |
| **高** | “冻结”仍改变普通策略 | 参数与 buffer 校验和、固定面板前后完全一致；检查共享 optimizer 和归一化层状态 |
| **高** | seed 名字不同，但实际随机轨迹重复 | 检查有效 seed 位宽、重置位置、actor 全局 RNG、隐藏世界与未来随机流的重复率 |
| **高** | 根、候选、重复续局被当作独立样本 | 记录来源谱系；按真正的来源对局/场景聚类，而非仅按 row id |
| **高** | 只报告改变动作或正收益的根 | 报告完整预定根分布、触发率及总体收益；current 不变的根纳入零差 |
| **中高** | value 读取的状态表示丢失阶段或历史 | 检查观察别名：不同合法历史是否被编码成同一个不可区分输入 |
| **中高** | 将缺少显式 chance node 当成唯一搜索缺陷 | 核对每次随机后继的合法动作、先验、value 是否与实际状态相符；正确的开放环采样可不显式建 chance node，但不能复用错状态的估计 |

其中第一项尤其值得强调：**引擎原语通过测试，不代表把这些原语组合成一个宏动作后，新的决策协议也通过了测试。**

## 十一、立即停止什么，以及失败后如何收缩

### 应立即停止

当前 AZ 转换模型代表 RL16 的命名和对照，应停止使用。当前合并随机后继、复用首次 prior/value 的搜索，不再产生任何训练标签。无法确认编码的 value checkpoint 应隔离，不凭输出范围猜测其含义。

逐色原语伪装成宏动作的标签管线应删除或明确重新定义。两个根的正态总体 CI、根据 soup 推断共同梯度方向、按非零结果筛选“有效学习样本”的做法，也应停止。

**不必删除原始轨迹。** 保留干净的 winner、动作、观察、来源与版本记录，很多数据只需要重新解释和重算，而不是重新模拟。

### 如果 V 失败

如果线性头失败、MLP 成功，就只更换读出，不解冻整个策略。如果只有原始观察 adapter 成功，就修 value 的表示接口，不把问题扩大为“需要更大的整个模型”。

如果三个探针在可靠标签上都失败，先把任务缩到**合法的近终局重掷状态**：更少存活角色、更少剩余牌、较短的真实续局，必要时选取可精确枚举隐藏状态的实例。仍然使用真正终局胜负，不把血量差伪装成终局奖励。

如果 value 能排序，但筛选真实收益依旧接近零，就停止扩大 opening teacher：这可能是候选改进空间小、当前续局限制了收益，或 value 对重要分歧仍不准。下一步转向 M，而不是继续枚举更多开局重掷。

### 如果转向 M

先做两个训练 seed、各 64 局的有限恢复实验，使用 native Q 回报回归、新环境数据、宏动作单位、无 PER，普通路径先冻结。它们只用于发现明显遗忘、是否产生可重复方向以及数据管线是否正常，不负责证明几个百分点的最终收益。

如果 M 也没有可识别信号，就停止全游戏长训练，把问题缩成同一批近终局信息状态上的价值拟合与动作改进。只有在这个缩小问题上证明**观察→动作→终局标签→更新**确实能产生改进，才重新扩大时间跨度和状态覆盖。

---

## 最终决策

**本轮批准：有硬预算上限的 V 诊断。** 它的产物应是明确的目标契约、价值可预测性证据、同根候选辨别能力和独立真实收益，而不是一张更漂亮的 MSE 曲线。

**唯一备选：native DMC。** 它无需等待 R 教师资格，但必须保持原生 Q 回报回归，不再被 policy-gradient、参数 soup 或经过损坏转换的 AZ 混淆。

**暂停：独立 R 扩大实验和当前 ExIt/MCTS。** 先手范围内的小型终局验证保留为测量工具，不发展成无上限的教师工程。

三个目标当前的位置是：

| 目标 | 当前状态 |
|---|---|
| 消除新重掷流程的分布外退化 | 仍未证明；行为异常的价值影响也尚未被可靠量化 |
| 恢复原 RL16 在当前环境中的能力 | 已明确必须使用原 native 模型作为参考，但没有新的稳定恢复证据 |
| 稳定超过 F1-D2 | 尚未进入正式验收阶段 |

**接下来最需要证明的不是“又修好了一个问题”，而是：在一个定义正确、预算有限、没有信息泄漏的比较中，模型确实能识别并利用一个可重复的动作价值差。** 这一步成立后，才值得继续扩大训练。
