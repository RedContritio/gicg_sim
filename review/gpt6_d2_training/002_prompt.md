# D2 训练路线第二轮独立审查

请继续作为强化学习、规划、不完全信息博弈和实验设计方面的独立研究审查者，复核第一轮建议落实后的结果，并决定下一步应优先做什么。

这不是要求为既有方案背书。请主动寻找实现错误、目标定义错误、统计设计缺陷和不值得继续投入的路线。当前尚未稳定战胜 F1-D2，请不要把“定位出问题”表述成模型能力已经提升。

## 目标与正式标准

环境是类似原神七圣召唤的 3v3 隐信息随机卡牌游戏。动作包括技能、出牌、切换、目标、支付、调和、结束回合和每回合重掷。

目标是在保持规则泛化能力的前提下稳定战胜固定 F1-D2 贪心基线。正式标准是：多训练 seed、独立测试 seed、双席位双布局，按场景聚类的 95% CI 下界高于 50%，同时 heldout 规则变体不明显退化。

不接受以下捷径：

- 给学习方接入 D2 的手工骰子策略；
- 使用“保留出战同色骰”等人工塑形奖励代替终局目标；
- 在 Web 或评估时用规则启发式兜底模型；
- 用已经参与选模的面板冒充独立测试。

## 第一轮审查后的路线

第一轮建议暂停原样 ExIt，先完成实现审计，再把重掷隔离成完整宏动作的反事实价值问题；教师必须先在独立样本上证明正收益，之后才能训练 reroll adapter。普通策略应结构性冻结，而不是依赖昂贵的蒸馏 anchor。

我们据此采用了以下阶段：

1. P0：审计 RL16→AZ 转换、动作索引、价值视角、RNG、chance、隐藏信息和回合时序。
2. C：冻结 RL16 普通策略，对完整重掷宏动作做终局反事实比较；候选发现和收益验证分开。
3. A：只有 C 通过后才恢复决策类型分层、初始无 PER 的 native semantic DMC。

## P0 审计结果

### 已确认通过

- 回合顺序：双方先掷骰并完成重掷，之后才触发 round-start effect。
- 引擎重掷原语、公开观察和动作编码通过现有契约测试。
- Python 与 Go 搜索均以 P0 视角存储 value，并在选择时按行动方转换；连续行动权不会机械反号。
- 状态快照精确保留 RNG；私有模拟可以显式设置 simulation seed。
- 合法动作数超过 `max_actions=2048` 时显式失败，不会静默截断；审计的 823 个状态中最大合法动作数为 98，但覆盖仍需扩大。

### 已确认失败或不具备资格

- RL16→AZ 不是行为等价转换。4 局、823 个同状态决策中，普通决策 argmax 一致率只有 71%，最大概率误差 0.608；重掷决策 argmax 一致率 97.6%。因此停止以转换后的 AZ 模型代表 RL16。
- 当前 MCTS 没有显式 chance node。相同动作历史下的不同随机结果合并到同一节点，并复用首次展开的 prior/value。因此现有搜索不能直接作为扩训教师。
- 通用搜索会从真实状态的 `hand_refs + deck_refs` 推导剩余牌表。虽然牌表本身应是公开知识，但接口尚未把公开牌表显式固定为输入，仍有信息边界风险。
- 后手重掷根需要建模“对手已经重掷后骰面”的条件后验；当前反事实实验只使用先手根。

## 完整重掷宏动作教师实验

一次完整重掷表示为八种颜色的重掷数量向量，运行时仍按引擎协议逐色提交。冻结 RL16 作为后续普通决策策略，固定 F1-D2 为对手。

续局会重新采样：

- 己方未来牌序；
- 对手手牌与牌库划分；
- 在先手重掷根中，尚未重掷的对手骰面。

候选发现与验证使用不同 seed。

### 32 根正式筛选

配置：32 个先手重掷根，每根 6 个候选，候选发现每动作 8 次续局，独立验证每动作 12 次续局。

结果：

- 平均根配对收益：`-0.0104`；
- 根状态聚类正态 95% CI：`[-0.0933, +0.0725]`；
- 7 个正收益根、13 个零收益根、12 个负收益根；
- 25/32 个根改变动作；
- 384 个验证配对中正差 40、负差 42、零差 302；
- 共消耗 486,840 个环境步和 237,134 次学习方网络前向。

按预先规则，区间跨零，教师没有取得资格，因此没有训练 reroll adapter。

### 完整候选枚举与独立复验

随后在 4 个先手根枚举全部合法重掷宏动作。只有 2 个根的 raw selection leader 不同于 current，另外 2 个根的 leader 就是 current。因此独立复验实际只覆盖两个非 current leader 根。

每根 64 次 paired validation：

- 对齐骰子 RNG：两个根均值 `+0.0625`、`-0.21875`；聚合 `-0.0781`，根均值 95% CI `[-0.3538, +0.1975]`；
- 不对齐骰子 RNG：两个根均值 `+0.03125`、`-0.03125`；聚合 `0`，根均值 95% CI `[-0.0613, +0.0613]`。

两种设置均无 qualified root。这组实验只能说明当前 opening teacher 未取得资格；由于只有两个非 current 根，不能全局否定反事实重掷学习。

## native DMC 与动作级反事实补充结果

### 终局 policy-gradient 单步更新

四个训练 seed 相对 acceptance 基线的变化：

- 932000：`+3.636pp`
- 932100：`-1.818pp`
- 932200：`-0.455pp`
- 932300：`+3.182pp`

均值 `+1.136pp`，但 two-level CI 跨零。四个 checkpoint 等权 soup 在新 seed 935000 上为 `38.636%`，RL16 基线为 `41.364%`，paired delta `-2.727pp`，paired 95% CI `[-6.818pp, +0.909pp]`。

这说明终局梯度暂未显示稳定的共同改进方向。

### generic common-seed pair

最初对通用动作做 common-seed 成对终局比较，256 局 × 4 repeats 后开发分数为 `30.0%`，基线 `31.818%`。

事后发现其中两个具体缺陷：

1. reroll 样本比较的是逐色内部原语，不是完整重掷宏动作；
2. 两个分支选择的重掷数量不同，会消耗不同数量的骰子 RNG，导致后续随机流错位。

因此该 reroll 标签构造无效。

切换为 ordinary-only 后，128 局 × 8 repeats 仍为 `30.0%`。只得到 31 条训练 rows，其中 17 条权重为 0.25，14 条存在 discordance。普通动作的成对终局偏好信号仍过于稀疏。

## 新发现：value 编码契约不一致

进一步检查发现，现有 value 工具曾混用两种编码：

- semantic RL 的状态 baseline 与 rollout advantage 使用 signed outcome：胜 `+1`、负 `-1`、平 `0`；
- 独立 `train_value` 会把终局结果转换成 win probability：胜 `1`、负 `0`、平 `0.5`；
- 搜索代码一度把加载到的 value 直接当作概率使用；
- checkpoint 没有始终显式记录 value encoding，旧权重存在解释歧义。

当前修复方向是：

1. checkpoint 显式保存 `value_encoding`；
2. loader 将旧/新 value head 统一转换成 signed outcome 内部表示；
3. 搜索边界再把 signed value 转成胜率；
4. value 训练和诊断显式拒绝无法判定编码的样本；
5. 冻结 backbone，只训练独立 value head，避免破坏原策略。

这里的最后一层是线性层，因此 probability 与 signed outcome 之间可以通过 `v_signed = 2 * v_prob - 1` 精确转换权重和 bias。但这只能修复尺度解释，不能证明 value 本身具有排序或校准能力。

当前正在加入针对完整重掷宏动作后继状态的 value 诊断。拟报告：

- MSE、MAE、bias；
- 分箱校准；
- 任意候选对的排序一致率；
- 相对 current 候选的方向准确率；
- 独立根、候选和终局 rollout 数量。

## 当前待决路线

### 路线 V：先建立可校准 value，再降低教师方差

1. 用当前规则下的新鲜完整终局轨迹，在冻结 RL16 backbone 上训练 value head；
2. 在未参与训练的完整宏动作后继状态上，用多次真实终局续局验证 value；
3. 只有 value 的候选排序与相对 current 方向判断通过门槛，才用它扩大候选筛选；
4. 最终 teacher gain 仍用独立真实终局 paired validation 判定，不用 value 自证。

### 路线 M：不再等待重掷教师，直接恢复 native DMC

1. 使用当前环境的新 replay，显式记录决策类型、环境版本、对手版本和数据年龄；
2. 初始关闭 PER，按 ordinary/reroll 等类型分层采样；
3. 从原 SemanticQNet 开始，不经过 AZ 转换；
4. 先保持策略 backbone 稳定，再根据固定普通状态面板与新环境胜率决定逐层解冻；
5. 把重掷作为同一终局目标下的合法动作学习，而不是等待独立教师。

### 路线 R：重新设计反事实教师

只保留完整 macro reroll。扩大能产生 non-current leader 的根状态覆盖，改进候选发现和方差控制，并补齐后手隐藏骰面后验。仍须先通过独立 teacher-gain 资格验证。

## 请重点判断

1. 当前证据更支持“教师方法本身不适合”，还是“前两版教师实现与估计器不足”？哪些结论已经足够确定，哪些仍不可识别？
2. value 编码不一致可能污染了哪些历史结论？哪些实验使用纯终局续局、因此仍然有效？哪些涉及 value/search 的结论必须重跑？
3. 路线 V 是否是合理的下一步，还是会把问题从高方差终局教师换成有系统偏差的 value 教师？
4. 冻结 RL16 backbone 训练 value 是否有足够表达能力？应如何快速判断“表示不足”与“数据不足”？
5. value 的哪些门槛真正与候选决策相关？请为校准、排序一致率、相对 current 的方向准确率给出建议的 go/no-go 标准，并说明样本单位应是 transition、candidate 还是独立 root。
6. 对大量零差 paired outcomes，应如何建模和分配预算？是否应使用顺序检验、方差自适应分配、控制变量、分层 outcome 或其他 estimator？
7. common random numbers 在不同重掷数量导致随机调用数不同的情况下应如何正确耦合？按“骰子/抽牌/其他随机事件”拆分随机流是否足够，还是应按语义事件索引？
8. 只有先手根的教师是否仍有研究价值？补齐后手骰面条件后验之前，是否应完全停止 reroll teacher？
9. 路线 M 能否在没有合格 reroll teacher 的情况下恢复新环境能力？怎样防止稀少重掷状态被普通动作淹没，同时避免反复过拟合同一批重掷根？
10. ordinary-only pair 只有 31 条有效 rows。这说明样本预算不足、动作差异本来就稀少，还是当前比较单位/更新目标设计错误？
11. 当前最小、最便宜、信息增益最高的下一组实验是什么？请控制在能够快速证伪的规模，不要默认扩大到长训练。
12. 如果 V、M、R 只能选一条作为下一步主线，应选哪一条？另外两条在什么证据出现后再启动？
13. 有没有我们尚未识别、但足以使全部结论失效的实现或统计风险？请按严重性列出检查方式。
