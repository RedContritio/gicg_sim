# 修复卡牌目标表达与条件学习（首次训练前登记）

2026-09-12。发现 v11 同牌同付款不同目标的 action_refs 完全相同，共享动作头也不编码
卡牌目标。先修复 C API / Go actor / 共享网络，再从零学习；v11 权重不得复用。

## 条件目标实验

- 环境：双方赤蝶、墨客；仅美味烧鸡；v_legacy/test_basic；12 万能骰；隐藏敌方骰子。
- 只通过合法切换、普攻、结束和打牌生成状态。每个种子覆盖己方 0/1、受伤角色 0/1、
  最终出战角色 0/1 的全部 8 种组合，训练种子 400–407，测试 93000–93003。
- 当前只比较美味烧鸡的两个合法目标，付款相同。通过克隆执行得到实际 HP 增量标签，
  确认两个目标收益分别为 0、1；不把标签作为网络输入。
- 每行只保留这两个合法候选（完整游戏动作集的子任务）；候选顺序按种子打乱。
- 复用正式 32 维 DMC 网络，初始化种子 41/42/43，AdamW 0.0003，批量 8，
  固定 200 次更新；所有并列最优使用均匀软标签，无早停/模型选择。
- 报告训练前后、逐角色/己方/出战情况命中率、每种子逐状态结果。
- 对照：随机/固定目标理论 50%；测试时仅将卡牌目标字段抹为 -1，保持状态和权重
  不变，验证目标信息确实决定区分能力。对照用并列最大 logit 均匀计分，不靠索引。
- 通过条件：三种子均达 90%，且信息抹除后回到 50%。即使通过，也只证明该目标
  子任务可学，不证明主动作选择、完整规则理解、RL 或最终迁移。

固定测试种子不用于修改预算。真实规则/观测/权重来源和完整合法前缀记录到新输出目录。
以逸待劳和速速茶点不参与。架构变更执行五范式完整 smoke。
