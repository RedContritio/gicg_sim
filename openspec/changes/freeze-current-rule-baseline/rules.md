## 证据等级与使用边界

- **U**：用户明确确认的语义，仅限下方引文及其直接含义。
- **P**：项目已有声明、注释及规约推导的工作规则，可以做实现回归；
  尚不能证明与设计者完整意图一致。
- **Q**：语义缺少独立依据或存在冲突，需裁定，不能计入认证通过。

其余未标 U 的数值与规则均为 P。源码哈希冻结的是可复现版本，不会把
P/Q 自动升级为 U。新增卡牌、改费、改结算顺序必须生成新版本并复验。

## 已确认的两项规则

**乘胜追击 U**：用户说明“每回合第四次需要消耗骰子的操作减少三个
任意骰子消耗”，并修正“减少的骰子消耗应该优先减少掉带限制的骰子”。
据此总减免上限为 3、受限费用优先，无色费用最后，不等于每个槽各减 3。

**以逸待劳 U**：用户说明“过量治疗也算”。治疗后反击按治疗事件量，
不按最终 HP 增量；满血接受 3 点治疗仍反击 3 点。

## 公共规则 P

- “无”表示任意颜色骰，“同”表示同色骰；指定元素骰可由万能骰代付。
  能量和骰子是独立费用，减骰不减能量。
- 普通行动牌是快速行动；蝶鳞、守正以及扩展牌以逸待劳是战斗行动。
  费用在效果前支付；天赋牌调用的技能不能重复收费、重复计操作数。
- 主动切换默认 1 无、战斗行动；死亡强制切换免费，不能消费主动切换
  优惠，不能作为乘胜的付费操作。快速行动致死、等待换人后保留原行动权。
- 食物选择己方存活角色；本回合饱腹者不能继续使用食物，后台其他角色
  不受其饱腹影响。回合末清除饱腹。治疗不超过 HP 上限。
- 装备按被选角色的武器类型检查；装备槽替换，不是按出战角色类型检查。
- 伤害顺序：改元素 → 加法增伤 → 乘法增伤 → 元素反应 → 减伤效果 →
  护盾 → 免疫 → HP 扣减 → 后置效果。穿透跳过反应与减伤/护盾。
- 回合末顺序：状态 → 召唤物 → 衰减 → 最终结算。每阶段先宣告结束方
  优先；死亡需要选择时暂停，选择后继续；游戏结束后不继续另一方效果。

- 以逸待劳：8 无、战斗行动、永久激活；回合开始生成 2 个己方出战元素

| Q01 | 乘胜是否统计激活前本回合的操作、激活自身操作？多个减费谁先消费？指定元素与同色都存在时内部顺序？ | 当前为激活后计数、其他折扣先、指定元素先；这是 P，用户只确认第四次、减 3、受限优先。现有测试锁回归，不视为完整规则确认 |
| Q02 | 佛跳墙是否限制技能/敌方目标、是否应回合末失效？西风剑给下一角色标记是否允许卡牌/状态伤害？ | 当前 DSL 无这些限制；不擅自改成官方习惯。新增组合只使用无争议的技能命中 |
| Q03 | 蝶印挂到后台后是否仍当回合触发或清除？致死主伤害后的印/回火追加应锁原受击角色，还是选择新的出战？ | 当前 round_end 只查敌方出战；after_damage 使用当前出战。未加入自证式断言，也未擅改目标规则 |

| Q05 | 多个同阶段减伤（如水云与荷花酥）是否由规则指定顺序，还是依赖文件注册顺序？ | 当前执行服从优先级、注册顺序；公共阶段顺序已验，但这个组合的设计意图未确认 |
