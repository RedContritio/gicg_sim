# Freeze current rule baseline

用户授权先完成当前牌组的规则清单与交互验收，作为可靠模拟环境的基础。
范围沿用 verify-current-cards：21 张实际用牌、赤蝶/墨客；以逸待劳与
速速茶点为已讨论的扩展用例，猫咪仅用于护盾机制夹具。

交付：可阅读规则清单、逐牌覆盖矩阵、手工推导的组合用例、可校验源码
指纹。源码指纹用于追踪变化，不作为规则正确性的证据。未得到独立说明
的语义保持明确标注；不通过现有执行结果生成期望值。

本批不启动训练、不扩充正式卡池、不开展随机对局压力验收。

冻结后的用户裁定见 [decisions.md](decisions.md)；已裁定条目优先于冻结时的待确认标记。
