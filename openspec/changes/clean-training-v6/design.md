# 设计与边界

## 产物入口

`training/core/artifact_io.py` 为文件权重和 NPZ 训练数据提供唯一读写入口。
标记含 schema、重置 epoch、规则/观测/训练源码联合 SHA256、进程 session 与已加载父产物 SHA256。
五范式保存、续训、热启动、对手/评估加载、BC 数据、CFR reservoir 和费用探针统一使用它。
缺少来源、旧 epoch、指纹不匹配时，先拒绝再进入网络/优化器状态加载。
旧 meta 3→18、buff 5→6 和缺少 buff encoder 的适配已删除；保留显式原语词表追加行。
回放导出带来源 sidecar；训练数据从当前引擎重新采集。原始 YAML 诊断回放解析仍可用，
它不是绕过 NPZ 训练数据入口的方式。只读检查工具允许检查文件，不加载为策略。

这是兼容性与误用防护，不是数字签名或规则正确性证明；手工伪造标记不在信任模型内。
指纹是当前仓库源码的保守快照，不能认证任意外部 data_dir、外部二进制或另一台机器上的源码。
运行进程缓存指纹；改变源码后必须重启。跨源码版本自动迁移默认拒绝，新增真实机制需另行验收。
进程内权重同步与 replay buffer 仍是内存对象，由已验证文件入口或本轮采样产生。
父文件列表是进程级保守来源集合，可能包含同一进程加载但未实际用于当前模型的文件。

## 实验

真实对局使用 DMC、当前共享网络（d_model=32，1 个 cross layer），3 个种子 41/42/43。
每种子基础预算 3000 帧；卡组整体留出；独立从基础权重微调 250/1000 帧，新优化器和空回放。
追加 1000 帧从零训练新环境对照。保存完整配置、逻辑计数、权重、来源、逐场评估结果。
辅助费用探针使用当前 HookEncoder/BuffEncoder 与引擎支付标签；这是监督任务，不是胜率。
原语扩展为受控表示实验：将已有减法编码成新 SUB opcode，词表 16→17。
语义及引擎标签不变；明确不声称引擎新增未知机制的学习已经验证。

评估固定 16 组独立环境/牌库种子，每组交换双方位置，对随机和 F1-D2 各打 32 局。
分别报告胜平负与 win+0.5*draw 得分，以局面对为 bootstrap 单位。
随机基线不得被覆盖 epsilon；非法动作和未结束到达步数上限不能静默记为平局。
同一组评估局面跨种子复用，跨种子均值仅作描述，不能将重复基线当独立样本。
