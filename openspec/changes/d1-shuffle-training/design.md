# 验收与当前实验

正式验收使用未参与训练与调参的场景、对局随机种子和布局种子，交换席位。
沿用胜加半平的成绩，同时报告纯胜率和平局率，避免以平局掩盖表现。
至少256个场景、每场景双席位，至少4个独立shuffle布局；所有对局必须正常到终局。
成绩要求：每个布局的点估计均>=50%，跨布局按物理场景聚类的95%下界>=50%。
鲁棒性要求：同物理状态至少4重排，逻辑动作一致率>=99%，报告含支付一致率与Q差异；
各布局成绩差异的配对区间须落在±5个百分点内。诊断集不作最终验收集。
这些是本次执行采用的保守验收标准，不宣称有限样本证明所有排列下都成立。

当前首个实验：沿用119000的物理轨迹和前6/后2场景划分，布局0/2/3训练，1/4仅评估。
原单布局诊断的布局1已被观察，仅作为开发对照；最终验收另用新种子。
固定400步正负平衡batch32，GPU计算，全网更新；原权重不变，结果保存于独立目录。
并行物理重放逐步核验视图、动作身份、支付和标签一致，避免把不同局面当成重排。

若多布局仍不能可靠迁移，应审计随机编号/位置进入语义编码的路径，并修正表示。
若诊断改善，再进入完整对局训练与D1评估，不因诊断通过而宣布目标完成。
