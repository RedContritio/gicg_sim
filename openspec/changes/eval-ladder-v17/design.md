# 版本化评估

五个基线：random、F1-D1-50%、F1-D1、F1-D2、技能滥用者。
混合策略每次决策独立选择D1或均匀合法动作随机；分支/随机动作/贪心平局各自有确定种子。
随机仍均匀采样引擎合法动作（包含支付展开），保留既存random定义。
技能滥用者按(player, character slot, original skill ID)记次数，选择技能时加一；
每次select_action对应一次提交，未执行选择不得重复调用。强制目标选择不增加次数。
回合改变清零，game_start清零，角色切换不清零；两次后考虑其他技能，无合资格技能结束回合。
费用仍取原始声明，按能量/异色优先/指定数量/同色数量/任意数量排序。
评估JSON包含version及评估源文件哈希。旧v16结果保留到eval_v16_archive；重新评估并要求
未改动的random和F1-D2逐局结果完全一致，禁止混合两版本技能滥用者分数。
训练指纹仍为v15，不改变优化器、经验池、奖励或训练对手混合。
