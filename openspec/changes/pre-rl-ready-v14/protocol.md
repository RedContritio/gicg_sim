# RL 前最终准备与固定辅助验证

范围：当前 readiness_base/tactics 的 1v1/2v2 初训配置，不扩到三角色或所有正式卡。
不启动正式 RL；完整 smoke 中的临时训练仅作工程验收。

1. Tune 动作传弃牌 canonical hook + 源骰色；共享头加入 tune 类型及颜色表达。
2. 每次预检决策检查 refs/payment → native identity 无歧义，允许同牌重复副本。
3. 辅助规则实验（训练前固定）：双方赤蝶/墨客，乘胜追击和两份美味烧鸡，12 万能骰。
   通过合法行动组合双方视角、未饱腹/0号饱腹/1号饱腹、乘胜后付费次数0..4。
   训练种子600..603，测试95000..95001，共120/60状态，布局与对局种子隔离。
   标签为下一技能是否减费、两角色是否可作为食品目标，来自实际合法动作及付款。
   输入使用正式公共 state encoder；候选动作/付款/合法mask替换为单一中性占位，
   只训练辅助分类头及共享编码器，禁止把标签的候选付款与目标合法列表泄漏给模型。
   三输出 BCE，按训练频率加权，批量8，AdamW 0.001，固定200次更新，初始化41/42/43。
   每种子每标签 balanced accuracy ≥90% 为通过门槛，报告多数类基线、逐样本预测。
4. 最终网络治疗目标复验：原v12协议同预算200步，改用训练700..707、测试96000..96003，
   初始化41/42/43；每种子准确率≥90%，抹除目标字段回到50%。不据测试调参。
5. 五范式完整smoke、Go/Python回归、实际配置无学习gate、清理旧数据/权重、新source manifest。
6. 冻结下一阶段短程RL的配置/种子/预算/对手/评估；不要求在RL前证明RL胜率。

以逸待劳、速速茶点继续封存。辅助实验不证明完整对局能力；上述验收通过只表示可进入
预登记的小范围RL。若任一门槛失败，记录失败并使用新开发协议诊断，不能偷偷扩大预算。
