# 设计

Tune 使用原有 N×3 引用：canonical 弃牌 hook 加源骰色。共享动作头额外编码
Tune 类型及骰色，与同牌免费打出区分；原有 card target 与 switch 槽位语义不变。
自动 gate 检查同 refs+payment 是否对应不同 native identity；相同卡牌重复副本允许。

辅助规则分类头只读取正式网络公共 state vector。构造输入时移除真实合法候选与付款，
避免从引擎标签反推答案。由合法动作构造乘胜计数、食品饱腹状态，标签直接由引擎
枚举/付款产生。完整网络治疗目标试验另行复验。固定预算见 protocol.md。

原始小计数经单一 log1p 和线性变换后不易学出局部触发边界。开发对照后，六个实体
数值字段统一加入四尺度 sin/cos 特征，同时保留 signed log1p 大小通道，合计54维。
它只改变神经网络表达，不静态展开动态规则，也不提供任何卡牌的触发布尔答案。
最终监督协议见 aux-final.md；早期两轮失败与原始指标保留，不能混称通过。

DMC 工厂同一实例重复调用返回同一个网络，并在创建前按 cfg.meta.seed 初始化。
serial collector 绑定 agent 实际消费的探索 RNG，保存和恢复的是同一个随机流。

新结构改变初始化随机流，回归因此暴露了原有缓存和容量边界。CFR reservoir 与 AZ
replay 在替换时先持有新样本静态引用，再释放旧样本，防止同局最后引用被提前删除。
PPO 前向明确拒绝超过 max_actions 或 refs/payment 不对齐的输入，真实环境测试
使用2048动作容量，不截断合法集合。初训仍选 serial DMC；这些修复维持共享架构回归。

完整恢复是独立于“加载权重可继续”的验收。serial DMC 声明 checkpoint_complete，
通用驱动为其保存经验池内容/抽样RNG、采样器局序号/换边与探索RNG、历史对手环/RNG，
以及 Python/NumPy/Torch/CUDA 随机状态。恢复缺少该结构时拒绝继续。
检查点位于完整迭代之后，包含当次历史快照和下一决策位置；失败的半次迭代不覆盖
可恢复检查点。keep_last_n 实际执行；完整 smoke 以最大训练步数增长验证继续运行。
真实 serial DMC 的连续4步与2步后恢复至4步逐项对比权重、优化器和全部运行状态。
这不把其他范式的 metadata-only buffer 或异步在途任务宣称为逐位可恢复。

生产源冻结期间运行五范式完整 smoke；最终基线包括脚本、协议、配置和验证报告。
正式 RL 从零初始化，运行前检查来源、必需的 gate 和预登记预算；辅助检查点不作
自动 warm start。已查看测试种子不作为后续 RL 独立评估种子。
