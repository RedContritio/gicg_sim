# 本轮追加确认：切换操作与角色变化

用户2026-09-12确认：超载强制切换应触发效果，同时区分“进行切换角色操作时”和
“角色切换时”。以下是本仓库采用的语义，不引申为所有官方卡牌版本的判定。

- 进行切换角色操作：玩家主动选择并执行切换；是否实际支付骰子不改变操作身份。
- 角色切换：出战角色确实发生变化，包括上述操作、超载/卡牌规则强制切换、阵亡换人。
- 主动切换满足两种语义；强制切换只满足第二种。对已经出战角色的重复强制设置不触发。

现有执行层已有区分：`on_switch` 接收实际变化事件，`ctx.action_context == Action.Switch`
限制为主动操作。费用/快慢速准备使用 `on_action_prepare`，但该钩子也会在合法动作
查询时运行，不能把查询当作已执行操作来消耗或计数。

当前脚本中的伏兵之术、瞬身之术、铁弓使用上述 Action.Switch 条件限制主动操作；
以牙还牙的元素跟踪直接监听 on_switch，因此跟随强制变化。这里说明的是事件分类，
不扩大到这些牌全部交互或未纳入初训配置的牌效验收。

v13 已实现强制切换派发实际变化事件；本轮补充主动/强制/无实际变化的分类回归，
原有阵亡换人、超载与暂停/克隆恢复回归继续覆盖。无需增加NN专用触发答案或改动生产源。
