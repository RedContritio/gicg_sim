# 实现与边界

## 公开暂停来源

continuation 增加值类型 `publicCause`，仅在已公开的技能、出牌、换人、准备技能执行和
回合阶段边界写入。它不是执行栈，不从 root 快照、DSL 局部环境、私有 hook 分支、随机数
或延迟闭包中提取信息。暂停恢复仍使用原有可复制重放机制。

在既有 EntityExecutionFrame=5 下增加 ProgramPublicCause=3 的一行，保持网络尺寸和类别词表：

| 行字段 | 来源行含义 |
| --- | --- |
| 0 | valid=1 |
| 1 / 2 | 公开动作的相对所有者 / 角色槽位，无归属为 -1 |
| 3 | complete=0，来源不是完整剩余程序 |
| 4 | CauseSkill=1、CauseCard=2、CauseRound=3、CauseSwitch=4 |
| 5 | 回合 hook 阶段；其他来源为 0 |
| 6 | 0，不虚构执行栈位置 |
| 7 | canonical 公开技能/卡牌的 active hook slot，未知为 -1 |
| 8 | ProgramPublicCause=3 |
| 9 | 当前根操作已完成的玩家输入次数（公开历史） |
| 10 / 11 | 0 |
| 12 / 13 | EntityExecutionFrame=5 / 无 counter 绑定 -1 |
| 14 / 15 | 公开选择的相对目标方/角色，无目标为 -1 |

技能/卡牌还在等待时不会被中途重放选择改写为强制换人的来源。回合阶段可以替换先前的
结束行动来源。准备技能使用其公开技能引用。无公开来源的 ExecuteEffect(native closure)
继续仅标记重放不完整，不伪造可学习规则。

完整后续程序仍可能存在观测缺口。初训限制固定队伍每侧最多两名角色：角色死亡需要
替换时，至多剩下一名可选存活角色。三角色多选死亡路径已有恢复与来源表达回归，但
这不证明任意同源不同私有控制流都可区分；扩大训练范围前需另验收。

## 环境稳定性与终局标签

ExportView 的 statuses 来自无序 counter map，原来相同状态的视图顺序可能变化。
仅对这个展示列表按名字、值、上限排序；真实 buff 队列及其 FIFO 顺序不变。

共享 `terminal_outcome` 严格接受 winner=0/1/2，2 为双方的零收益平局，未知/未终局拒绝。
文件评估入口修正了把 2 记为失败的问题；独立评估遵守训练配置的显式牌组和步数预算，
预算用尽不生成平局。DMC serial、Python MP buffer 入口和 EpisodePolicy 拒绝未知标签，
serial 对局未终局或策略动作越界直接报错。DMC smoke 上限从 30 调整为 512，不能以
短截断构造 Monte Carlo 标签。本次初训配置为 serial；未来远端/Go actor 数据完整性仍需独立联测。

## 无学习预检

`tools.experiments.prepare_training` 使用生产 config loader 和 env factory，覆盖模型实际
配置、有限数值、动作/引用/费用对齐、敌方骰子和 RNG 隐私、反复只读查询、逐步 clone
与 snapshot restore 差分，以及真实小模型前向。分别使用按动作类别均衡和优先技能的
测试策略。全程不优化，结束时逐项比较模型参数未变。

每场失败记录配置、种子、策略与准确动作索引/标签前缀；报告先标为 running，失败写
failed，防止复用旧 passed 文件。报告绑定解析后配置、源码来源指纹和共享库 SHA256。
随机测试策略只用于环境覆盖，不输出供训练或模型选择使用的轨迹。

这套预检仅接受 DMC、敌方骰子遮罩、固定最多两名角色的配置。边界检查是有限验收，
不证明所有动作组合都正确；Go 的随机状态差分、专项规则/连续死亡/回合恢复测试补足覆盖。
