# 验收矩阵

| 场景 | 验收 |
| --- | --- |
| 读取未注册 buff 的修正 | 自动审计拒绝 |
| 删除 order、定义引用或 IR | 自动审计拒绝 |
| 六份当前训练配置 | 解析继承及实际队伍、牌池、牌组后逐一审计 |
| 普通对局随机动作序列 | 原局、克隆、池化快照、checkpoint、完整回放一致 |
| 死亡后等待替补选择 | 克隆/池化快照及后续执行一致；文件 checkpoint 保持既有拒绝语义 |
| 随机独立层生成/抵消/过期/整组清空 | 与独立数组参考模型一致 |
| 敌方触发己方独立层 | 模板读取与消耗属于己方，双席位回归 |
| 无召唤物且对方已结束 | NN 可区分下一次行动是否交回对方 |
| 切换先结束方、回合上限、固定骰规则 | 公开观测改变；双视角字段正确 |
| 改 RNG、生命周期序号、敌手手牌身份 | 不泄漏到 NN；敌手手牌数量仍可见 |
| 增加 counter 导致槽位溢出 | 静态/动态编码明确失败 |
| v4 权重适配 | 旧 meta 投影前三列保留，新列置零；微调可获得新列梯度 |
