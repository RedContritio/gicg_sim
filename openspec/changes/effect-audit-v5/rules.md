# v5 规则基线

继承 [v4 规则](../buff-lifecycle-v4/rules.md)，包括用户暂定的双方结算顺序。
本次不新增卡牌数值或未经确认的裁定。

## 实现修正

- 玄冰保留 priority=1 的反应拦截类别，同时按其 buff 实例调度并提供可见规则引用。
- 铁剑、铁枪、铁弓的费用/增伤/技能/切换效果补齐装备实例绑定；原卡牌数值保留。
- 实例 hook 内省略所属方的 counter 操作采用该实例所属方，不继承敌方触发者。
  伤害来源仍使用事件帧或显式 actor；二者不能混淆。
- 公开决策元数据扩展为 18 字段：前三项不变，新增结束声明、先结束方、回合上限、
  待选动作类型/强制标志，以及固定骰模式与八类骰子的配置。
- 静态/动态 counter 观测容量溢出明确失败，不静默截断。

旧 manifest 保持冻结；本版覆盖新的实现和验收代码，不等同官方规则认证。
