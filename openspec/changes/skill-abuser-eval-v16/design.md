# 原始费用排序

优先级按元组降序比较：能量、指定颜色类别、指定数量、同色数量、任意数量。
指定颜色类别：存在异于当前角色元素的指定要求=2；只有本色要求=1；无指定要求=0。
所有数字取引擎DSL加载后的SkillRef.Cost原始声明，不取当前支付或减费结果。
同级按技能声明ID升序；同技能支付使用既存省骰策略。只看合法技能，不使用行动牌、
主动切换或调和；无技能时结束。强制目标/切换及初始出战选择取首个合法选项。
Go工具通过canonical factory导出声明，Python按角色名+技能名匹配，缺失时明确报错。
实现位于tools而非训练核心，生产训练来源指纹不变；没有放宽检查点兼容校验。
