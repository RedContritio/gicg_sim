# v4 当前训练池规则基线

本版继承 [v3 规则](../buff-instance-learning/rules.md) 的卡牌数值、费用与用户裁定。
旧版文件保持冻结；下列更新覆盖旧版对应条目。范围仍是当前训练配置实际引用的自定义牌及依赖。

## 本次用户临时裁定（2026-09-11）

- 双方召唤物区：先宣告结束的一方先结算；同一方内按 buff 产生顺序。
- 其他 buff：跨双方按全局产生顺序。
- 保留已有结算阶段和类别：状态、召唤物、衰减、最终系统结算；同类别再排序。
- 这是用户要求先实现的临时规则，待用户核对实际规则后另建新版本。

## 已确认且本次修复的行为

- 以逸待劳：治疗量包含过量治疗。治疗或吸收触发的反击属于支援持有方，目标相对该方解析。
  敌方发起治疗也不会反击错对象。Q04 关闭，双席位 HP 与奖励归属回归通过。
- 蝶印：挂在敌方具体角色，逐枚按全局顺序结算，后台仍受 1 火伤后清除；死亡消失。
- 泼墨：己方队伍状态，生产者死亡后仍保留；两次、两回合的原数值不变。
- 荷花酥条件归零先于水云等普通减伤，再到护盾；类别内 FIFO；无收益不消费。
- 乘胜追击从打出后开始计数，打出本身不计；减费优先指定元素、同色、任意，合计最多 3。

## 实现约束

同一事件开始时固定有资格参与的实例。轮到之前被清除的实例跳过；新建或清除后重建的实例
从下一个事件开始参与，不顶替旧实例。持续效果补层保留原位置，引用型装备替换产生新生命周期。

现有卡牌仍按既有刷新/叠层规则使用聚合实例。新效果可以显式使用独立实例，每层有自己的次数与期限。
新增原语不自动改变既有牌的叠层语义。范围外的旧卡仍须逐项迁移、核对，不能据此宣称全卡池已认证。
