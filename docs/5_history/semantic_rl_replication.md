# 固定监督起点的五RL种子复现

2026-09-13。四个新增训练种子均完成预定预算，连同原试验共五个；全部报告，无失败或剔除种子。
结果支持：在当前固定BC起点和固定任务中，RL提升可跨训练随机种子复现，shuffle鲁棒性保留。

## 方法

固定BC权重、超参、8轮×128完整对局预算，只改变训练master seed。
新增132000/133000/134000/135000，原种子128000作为已有试验另行标记。
训练采样、环境/布局与minibatch随机性均由master seed控制；不改变BC初始化权重。
每个种子按开发seed129000最高成绩选checkpoint，并列取最早轮数；统一写selection.json后才观察新holdout。

独立holdout seed136000：256物理场景×双席位×4布局，每模型2048局，BC+五RL共12288局。
各模型均正常终局，无平局；各自四布局成绩完全相同。

五个种子平均胜率84.26%，平均配对提升**3.20个百分点**。
同时重采样训练seed和物理场景（双轴bootstrap10000次，共享BC和场景抽样），平均增益95%区间**[+1.56,+5.08]个百分点**。
仅算四个前瞻新增种子：平均提升**3.08个百分点**，区间**[+1.37,+5.08]**。
每seed增益标准差1.08个百分点。上表单模型区间未做多重比较校正，主要结论使用跨种子平均区间。
每个模型在两个角色席位都比BC点估计更高，改善通常在墨客席位更大。
