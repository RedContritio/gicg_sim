# 五练习角色1v1平衡性评估

2026-09-13。角色数值未修改。23,040局在56完成，约452.1秒。

结论：当前1v1任务存在明显强度差异，刻师傅在两档策略和两个起始牌组中均居首；墨客在D2下弱势。天星对策略深度敏感，不能仅凭D1低分加数值。

## 协议

角色赤蝶、墨客、猫咪、刻师傅、天星；10个非镜像配对与5个镜像配对。每配对128随机场景×交换席位=256局。
双方同为F1-D1或F1-D2，dice_greedy=True，不设搜索节点预算；三个环境current8、blank8、current10，合计15×256×2×3=23040局。
current8沿用当前训练的两张测试行动牌和填充；blank8起始牌组仅碌碌无为，仍保留角色自身产生的复刻等牌；current10仅将当前环境上限改为10。
固定master139000，各角色交换席位时携带自身牌堆和策略平局选择seed；环境seed配对、布局独立shuffle。
得分=胜+半平。角色总体对其余四对手等权，镜像单列，不用镜像填平总分。置信区间按物理场景bootstrap10000次，保留跨席位及跨对手同seed相关性。

## 回合上限与镜像

8回合上限在引擎中直接判平，不比较剩余HP；DSL第10回合按存活人数结算，人数相同时判首回合后手胜（data/system/timeout.lua），并非自然分胜负。
current8→current10的非镜像D2总体得分变化最大仅0.20个百分点，非镜像强弱排名几乎不变。
猫咪镜像D2：当前牌组8回合平局率48.05%；10回合虽然无平局，但有46/256局（17.97%）双方仍存活、由超时后手胜规则决定胜负。仅填充8回合镜像平局率82.03%。因此不能把10回合的零平局解读成自然分出了胜负；防御镜像需单独报告终局规则影响。
镜像先行动方得分随角色、策略、牌组变化，全部数值见summary.json mirrors；角色A/B交换席位后的分数不强行设成50%。

## 解读与后续

1. 优先审查刻师傅的技能/复刻/附魔收益，确认胜势来自预期规则后，再讨论削弱幅度。本轮未证明是哪一个机制单独导致优势。
2. 墨客在D2下持续弱势，需结合技能组合回报与策略使用情况分析，不能仅按面板伤害加数值。
3. 天星D1→D2变化约30个百分点，策略对盾、召唤物的利用能力是重要混杂因素，暂不凭D1表现增强。
4. 扩任务时建议使用逐配对成绩、至少两档对手；下一步再看2v2，才能评价后台伤害、队伍增伤和治疗/护盾协作价值。
这些是同强度启发式策略下的1v1结果，不是最优策略平衡结论，也不能外推团队强度。F1两档仍共享同一评分函数。
