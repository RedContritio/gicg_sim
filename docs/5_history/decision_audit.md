# NN 对 D1 决策诊断：2026-09-13

结论：主策略的终局价值估计存在明显失准；当前样本不支持将主要败因归为提前结束，
也不支持直接把 D1 全部动作作为正确答案。表达能力与学习信号谁是主因仍未确定。

## 基础行为

- 正常对局 7 胜 9 负；仅是诊断采样，不替代原 64 局评估。
- 277 次决策中有 196 次动作索引与 D1 不同，其中 63 次只是同一逻辑动作的支付不同。
  这是支付差异，尚未证明浪费骰子。
- 89 次即时 F1 低于 D1：56 次调和、19 次打牌、14 次技能。
  调和和铺垫本就可能牺牲即时血量收益，不能直接计为错误。
- 有技能可用却结束回合：0 次。这轮未复现先前 30k 退步模型的该项行为。
- D1 可以立即获胜而 NN 没有立即结束的情况：5 次，来自 3 局，最终全部获胜。
  其中多次先调和再完成斩杀；不能把这 5 次当作输局原因。

## 更明确的信号：终局价值失准

12 个实测 D1 动作可以立即获胜的状态中，8 个该动作的 Q 为负。
例如游戏 6、step32，D1 技能一步获胜，Q=-0.787；NN 选择调和，Q=-0.505。
随后 NN 又调和一次，最后用该技能获胜，其选中动作 Q 仍为 -0.806。
这表明即便最终行动成功，数值估计也可能与终局回报相去甚远。
这些状态有同局相关性，12 不代表 12 个独立局面分布样本。

只读检查了远端实际 `_episode.play_one_episode` 与 `terminal_z`：按 agent_side 转换终局胜负，
胜 +1、负 -1、平 0。最终经验池 6005 条，2666 条 +1、3339 条 -1。
没有发现这处转换代码把胜负符号反转；检查标签集合本身不能证明全部历史标签正确。
此处证据支持价值估计失准，尚不能定位到容量、编码泛化或优化中的某一个原因。

## 同局面配对续打

下表为将首步从 NN 改成 D1 后的分数变化，分数为胜加半平。

|后续己方控制者|D1 首步更好|NN 首步更好|结果相同|平均变化|按源对局 bootstrap 95% 区间|
|---|---:|---:|---:|---:|---|
|NN|3|1|28|+4.7 个百分点|[-3.1, 12.5]|
|D1|2|3|27|-3.1 个百分点|[-9.4, 3.1]|

结果受后续策略影响，不能把 D1 即时最优自动当作长期最优。
例如游戏 12、step3，NN 打牌，D1 选择即时多 2 点 F1 的技能：两次 NN 续打中，
NN 首步均负、D1 首步均胜。这是一个值得复核的失误候选。
但同局 step14，NN 打牌而 D1 结束回合，两次 D1 续打中 NN 首步均胜、D1 首步均负。
因此全盘模仿 D1 也可能损失有价值的决策。

## 下一步判断

应优先建立小型“确定终局价值”诊断集：能立即获胜的动作、确定失败的动作及近终局状态，
在原始样本与独立 shuffle 布局上分别验证 Q 拟合和动作排序。
用隔离模型副本进行有界拟合才能进一步区分：训练样本都拟合不了、只会记住布局，
或能够拟合泛化但正常 RL 中缺少足够监督。此项尚未执行，不能提前给原因下定论。

当前续打固定隐藏状态，只改变未来随机种子；每状态仅两次重复，且状态来自 NN 访问分布。
它估计的是特定续打策略下的条件结果，不是信息集最优价值，也没有全面审计支付质量。
