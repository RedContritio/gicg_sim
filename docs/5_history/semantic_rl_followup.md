# 监督对照与首轮RL微调

2026-09-13。用户要求补未训练新网络、D2老师对照，并从监督权重继续RL。
结论：当前固定卡池中，监督训练明显有效；一次终局奖励RL微调在独立配对场景上进一步提高3.32个百分点，同时保持shuffle稳定。
这不是从零开始的纯RL，也不证明新卡泛化；目前只覆盖一个训练种子。

| D2老师 |65.23%|[59.38%,70.70%]|

均0平局，四布局成绩一致。监督减D2的配对差12.50个百分点，区间[7.42,17.58]。
未训练网络采用确定性argmax，并非均匀随机策略；这个0%不能推广到所有随机初始化。
监督高于D2说明不能把结果完全解释为复制老师；D2随机打破并列、网络确定性选择、模仿偏差等因素尚未拆分。

## RL方法与验证

配置 `configs/dmc/semantic_goal.toml`。监督step2000初始化，输出作为策略logit；不把监督输出当成回报Q。
按softmax采样，仅最终胜负平奖励+1/-1/0，无D2动作标签，D1对手。
无critic的策略梯度，PPO式ratio裁剪0.2、旧策略近似KL>0.02停止本轮；上一轮席位回报EMA作baseline。
对冻结监督策略施加KL系数0.02，熵系数0.001；AdamW lr1e-5，每轮最多2epoch、batch32、grad_clip1。
训练8轮×128局共1024局，19358条决策，1218次更新；seed128000，所有shuffle开启。

56用16进程采集/评估，GPU更新。训练加逐轮开发评估总172.4秒。
小预算恢复验证：run000002第1轮→run000003第2轮，优化器步数10→20，baseline/settings/anchor保持连续。
本机真实采样log-prob与训练端一致性、胜负梯度方向、非法动作屏蔽、冻结anchor、原语义网络/buff回归共14测试通过。
新增工具ruff通过。候选检查点严格生产指纹加载及SHA校验通过。
