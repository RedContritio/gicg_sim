# v14 首次三种子小范围 RL

日期：2026-09-12。状态：三组训练及全部896局初始/最终评估完成，**未通过首次RL门槛**。
41、43进步，42退步；当前证据不支持稳定可重复学习，也不能据此判断表示方案不可行。

## 固定设计

用户在环境准备完成后授权继续，执行已登记的
[首次 RL 协议](../../openspec/changes/pre-rl-ready-v14/rl-protocol.md)。
配置 `configs/dmc/pre_rl_small.toml`，赤蝶对墨客的基础1v1场景，最多8回合。
共享网络278,880参数，DMC终局回报回归，三个种子41/42/43分别从零初始化。
每种子3000 agent frames，按完整对局收集，因此可能略超过预算；不是3000对局。
CPU serial、每组一个采样器，三个独立进程同时运行在本地macbox.local。
`OMP_NUM_THREADS=1 MKL_NUM_THREADS=1`；本次未使用5070Ti。
对手配置为随机0.4、F1-D2 0.3、本轮历史策略0.3；历史环为空时回退到随机。
未加载辅助任务或任何旧权重，未调整训练预算或根据评估选择中间权重。

评估master seed98000，32个场景各换边两次，每种策略、每种对手64局。
训练前评估三个初始化网络及均匀随机策略；训练后只评估各运行最终检查点。
得分为胜率加一半平局率。报告以场景为单位的配对bootstrap 95%区间，
保留换边相关性；前后差值也在同一场景上配对。样本量小，达标不等于统计显著。

预先判据：三组对随机得分均>0.5；对F1-D2相对初始化平均改善≥0.05；
对F1-D2至多一个种子退步。失败进入诊断，通过才另登记2v2。
98000已用于本次评估，后续调参后不得再将它视作独立最终测试。
以逸待劳、速速茶点继续封存。
