# 三种子 30k 训练分析

2026-09-12。只读分析，未追加训练、改规则或覆盖任何检查点。
基于远端原训练源码、固定开发评估、最终评估、历史直接对战、训练行为日志，
另在远端 CPU 上对种子43的20k/30k模型做512个固定经验状态的前向比较。

## 结论

模型在前期确实学到能力，但训练不保证越长越好。种子43在20k→30k发生明显退步；
种子42在12k附近较好，此后波动；种子41的后期下降相对温和。
预设门槛通过仅表示三个最终模型对随机得分超过0.5、F1-D2平均提升等条件满足，
不能解释成三个种子都稳定提升。最终43低于其多个早期检查点。

## 为什么训练过程的平均值没有报警

按每个阶段末尾100局统计，43的“有技能可用却结束”占技能可用决策的比例：
20k附近7.2%，25k附近6.6%，30k附近6.2%；同期训练得分49.5%、45.0%、47.0%。
这个统计混合了不断更新的策略、epsilon=0.2探索、不同对手和不同状态分布，
不能当成最终确定性策略在固定状态集上的行为指标。

### 固定状态、固定输入的模型比较

从43的20k、30k完整经验池分别随机抽取256条记录（固定抽样种子114001），
对两模型使用完全相同的状态和合法动作，eval模式、CPU、无探索、无权重更新。

|状态来源|20k模型有技能却结束|30k模型有技能却结束|动作索引改变|动作类别改变|
|---|---:|---:|---:|---:|
|20k经验池（180个技能可用状态）|1.1%|12.8%|57.8%|38.3%|
|30k经验池（190个技能可用状态）|2.6%|11.6%|64.5%|42.2%|

最佳技能相对结束动作的平均Q差：旧状态0.130→0.036，新状态0.128→0.042。
因此至少存在明确的技能/结束相对价值排序变化，而且并非仅支付方式索引变化。
“有技能却结束”不是必然错误，仍可能有战术价值；尚未用对局干预证明它解释多少掉分。

对经验里当时执行动作的MC标签计算MSE：

|经验来源|20k模型|30k模型|
|---|---:|---:|
|20k池抽样|0.157|0.401|
|30k池抽样|1.373|0.185|

这呈现“更适应新样本、对旧样本误差增加”的现象。MC标签来自当时的策略/对手，
不是最优Q真值；两行不构成独立测试集，也不能把拟合旧标签等同于保留最佳策略。
抽样前向均有限值，未观察到NaN/Inf；不能排除未记录的训练瞬时数值问题。

## 已排查与仍未证实的原因

- 恢复异常：43回退到完整检查点后重跑48局，原记录与重跑记录的种子、动作计数、
  对手、席位、回报等全部逐项相同；分析按ep_idx保留最后一条。这支持恢复没有改变
  这些已观测行为，不能声称完整浮点状态逐位相同。
- 硬件切换：20k和30k均在同一Windows/CUDA环境训练，不能只用Mac→CUDA解释这段下降。
- 训练对手：随机40%、D2 30%、历史30%；历史环仅5个快照，每50局更新一次，
  大致覆盖最近250局，而不是长期锚点。旧强策略会被移出。
- 经验池：FIFO容量10000。43的20k池total_seen=20019，30k池=30017，
  新增9998条，旧池几乎完全被替换。这是旧样本记忆消退的一个合理机制候选。
- 学习率固定0.0003、每局4个batch、batch32；没有后期降速。它可能放大排序漂移，
  但当前没有单变量实验支持“学习率就是原因”。
- 池内平均回报0.0868→0.0873，整体正负标签比例基本不变；不能只归因于负样本突然变多。
- 日志仅有iter/硬件指标，没有持久化loss、Q统计或梯度曲线，无法回溯退步发生的精确更新点。
  原因是pipeline记录迭代时传入空breakdown；本次没有修改生产日志或训练代码。

综合判断：43的策略退步有明确证据，最终模型更倾向于在可用技能状态结束回合；
近期样本替换、近期历史对手和固定更新强度与观察相容，但因果关系仍需控制实验。
不能据当前材料归因为环境规则错误、角色不平衡或模型容量不足。

## 建议的下一步

1. 暂停加长训练，以41的20k、42的12k、43的20k作为候选检查点；候选仅由开发曲线
   提出，不能将原最终测试集再当作未见数据。用预先固定的新诊断场景验证候选对终点。
2. 先对43的20k/30k做相同场景的确定性对局行为采样，记录结束动作Q与最佳技能Q，
   然后做仅在“有技能却结束”时替换动作的后验干预，估计这类行为实际贡献多少掉分。
   干预用于诊断，不直接把“禁止结束”写成规则。
3. 若确认更新造成持续漂移，从同一个20k完整检查点做有界单变量对照：
   优先只降低学习率（例如0.0003→0.0001），其他种子流、训练长度、对手与经验设置一致。
   之后才单独检验固定强历史锚点或旧经验保留，不同时叠加PER、奖励修改、网络扩容。
4. 为下一轮持久化固定状态探针、Q差、选中动作MSE及分角色开发评估；保留最佳开发
   检查点与末尾检查点。训练更久仍可作为实验，但不把“最后一个权重”默认当最佳模型。

本轮没有实施上述新训练或对局干预。
