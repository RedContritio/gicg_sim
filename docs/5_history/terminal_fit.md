# 隔离终局拟合诊断：2026-09-13

状态：400 步隔离拟合完成。模型能够拟合原布局训练样本，跨布局和未见局面仍存在明显误差。
已标注正负动作的相对排序有所泛化，因此不能将结果描述为完全不会学习或完全没有泛化。

## 样本与对照

以联赛主策略初始化独立副本，原训练检查点不修改。固定采集 8 场景交换席位，
在近终局状态枚举经骰子支付启发式筛选的候选动作，只标注已到终局的分支。
相同物理轨迹在独立 shuffle 布局中重放，逐步核验视图、动作身份、支付及终局标签一致。
共35个状态、67个动作标签，分布如下：

- 22 个直接获胜动作；4 个直接失败动作。
- 41 个行动后固定 D1 应对一步即失败的动作。这是条件标签，不代表对任意对手均必败。
- 前6场景：28状态、54标签（18正、36负）；后2场景：7状态、13标签（4正、9负）。
- 第二布局从不参与优化，留出场景也不参与优化。

副本使用 AdamW，lr=0.0003，无权重衰减，正负各16样本组成batch32，有放回抽样，
固定400步，全网更新。没有将未终局动作标为负例，也没有把 D1 所有动作作为正例。
固定预算结束后保留 diagnostic_only 权重，不用于正式游戏策略或对手池。

## 最终结果

|面板|拟合前 MSE|拟合后 MSE|拟合后符号正确率|拟合后混合状态排序|
|---|---:|---:|---:|---:|
|训练原布局|1.0544|0.000306|100.0%|7/7|
|训练同状态重排|2.1250|0.9415|72.2%|7/7|
|留出原布局|1.0120|0.9043|69.2%|3/3|
|留出同状态重排|2.9314|3.2447|53.8%|3/3|

训练 MSE 第1、25、100、400步约为1.0456、0.3511、0.0661、0.000306。
最终训练正类MSE为0.000151、负类0.000383，排除了靠恒定输出单一类别通过的情况。
但同样训练物理状态换布局，负类MSE仍为1.2328；未见场景的重排布局负类MSE为4.6249。
后者正类MSE下降到0.1392，显示主要是部分负动作被高估。符号正确率与MSE可能反向变化，
因为更少但更大的数值误差仍可推高MSE。

拟合前只换布局，19/35状态改变了动作，其中15次逻辑动作变化、4次仅支付变化。
拟合后11/35状态改变动作，其中7次逻辑动作变化、4次仅支付变化。
留出7状态动作不再随布局变化，但标注动作Q的布局差仍大（平均绝对差1.187），
不能把动作一致直接解读成价值正确。

**诊断判断**：这批样本本身可以被当前网络拟合，尚无依据把主要问题归为绝对容量不足。
原布局到同状态重排布局的差距直接暴露布局泛化问题；留出原布局也保持较大误差，说明
新物理状态泛化同样有限。样本很少，不能断言只有布局是瓶颈。
相对正负排序改善说明学到了一部分可迁移信号，但没有对全部合法动作或整局胜率做新评估。

**下一步建议，尚未执行**：在保持物理训练样本不变的前提下，为每个状态加入多个训练重排，
保留完全未用过的重排作为测试。这样能进一步区分覆盖不足与结构性的布局依赖；
再据结果决定增加重排训练还是调整表示。不能用这次监督拟合实验否定更长 RL 的潜在收益。
