# 网页对战界面调整 · 2026-09-14

## 实现

- 按七圣召唤截图的空间关系组织棋盘：敌上我下，支援左、角色中、召唤物右、骰子最右；选择 P1 时己方仍在下。
- 角色卡展示卡图、生命、充能、状态和出战位置；插画取自仓库官方资料快照中的 URL，加载失败回退文字卡面。
- 敌方只展示手牌数量/卡背与骰子总数。服务端同时隐藏手牌身份与骰子类型，不只是前端遮挡。
- 点击卡牌/角色先筛选行动，再选支付执行；卡牌面板包含调和，目标显示己方/敌方及名称，避免镜像阵容歧义。常用技能和结束回合留在行动栏，设置和记录折叠。
- `record.ExportView` 的区域数据来自实际支援槽和带 Summon 标识的 buff 实例，不按效果中文名猜测类别。不改变引擎规则、NN 观察或远端训练。
- 明确标注的随机练习对手可沿用 native profile 开局；不绕过 RL checkpoint/报告指纹检查，不把随机对手当作 RL。
