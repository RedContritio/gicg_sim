# 训练方案

## 1. 训练难度分析

直接训练全量游戏几乎不可能收敛，原因：

| 维度 | 复杂度 | 影响 |
|------|--------|------|
| DSL 感知 | 网络需先学会"读懂规则"才能做决策 | 前置瓶颈 |
| 角色数 1→3 | 切换决策、集火策略、死亡切换 | 动作空间 x3，策略深度剧增 |
| 卡牌 L1→L6 | 高级卡有条件效果和跨角色联动 | 观测维度 x5，稀疏奖励信号 |
| 元素反应 | 7 种反应，连锁结算 | 状态空间爆炸 |
| 对手强度 | 自博弈非平稳环境 | 策略循环、遗忘 |
| 不完全信息 | 手牌/牌堆隐藏 | 推理难度 |

## 2. Instruction Encoder 预训练

在 RL 课程之前，先单独训练 Instruction Encoder 学会"读懂 DSL"。

### 核心思路：执行跟踪预测

用引擎跑大量随机对局，采集每步的 hook 触发记录。训练网络预测：在当前状态下，如果这个 hook 触发，哪些 counter 会变化，变化多少？

Shuffle 是关键——没有 shuffle 网络可以死记 "位置 5 = HP"；有了 shuffle 必须通过 AST 理解语义。

### 数据生成

```
引擎配置：随机策略双方对局，全量记录
每步记录：
  - 当前 counter 快照（shuffle 后）
  - 触发的 hook 的 AST（shuffle 后）
  - 执行后 counter 变化量（delta）

生成量：10 万局随机对局 ≈ 300-800 万样本
引擎速度：Go + LuaJIT，单线程约 1000 局/秒，64 线程 ≈ 数分钟完成
```

### 三阶段预训练

**Stage P1：单步预测（基础 DSL 理解）**

```
输入：(Counter 区 [Nx3], Hook AST 区 [MxD], 执行的动作 ID)
标签：每个 counter 的 delta (value_after - value_before)
损失：Huber loss
数据：仅 L1-L2 卡牌，1v1 同角色
```

网络学会读简单 DSL：`deal_damage(target, FIRE, 3)` → "某个 counter 会减少 3"。

**Stage P2：复杂 DSL 理解**

```
输入：同 P1
标签：同 P1
数据：逐步扩大到 L1-L4 卡牌，1v1 异角色（引入元素反应）
```

网络学会读条件分支和连锁效果。

**Stage P3：多步预测 + 价值热启动**

```
多步预测：
  输入：(Counter 区, Hook 区, 连续 3 步动作序列)
  标签：3 步后 counter 状态
  训练连锁推理：泼墨追加伤害 → 元素反应 → 连锁 hook

价值热启动：
  输入：(Counter 区, Hook 区)
  标签：该局最终胜负（来自随机 rollout）
  给 Value Head 一个粗糙但非零的初始化
  数据：L1-L6 全量，1v1 + 2v2
```

### 预训练产出

```
冻结权重：Instruction Encoder (AST Token Encoder + Self-Attention)
可选保留：预测 Head（作为 RL 阶段的辅助损失）
迁移到 RL：State Encoder + Grounding Attention 从 P3 热启动
```

## 3. RL 分阶段课程

设计 9 个训练阶段（Stage 0-8），每阶段解锁一个维度的复杂度。

**Instruction Encoder 冻结**（或极小学习率 1e-6 微调），仅训练 State Encoder + Grounding Attention + Policy/Value。每阶段网络权重继承自上一阶段。

### Stage 0：基础操作

```
场景：1v1 同角色镜像赛
卡牌：L1
对手：随机策略
```
目标：使用技能、管理 AP、适时结束回合。
毕业条件：vs Random 胜率 > 90%，平均回合数 < 8。

### Stage 1：技能策略 + 简单卡牌

```
场景：1v1 同角色镜像赛
卡牌：L1 + L2
对手：随机 → 贪心
```
目标：合理选择技能、管理能量、使用即时效果卡牌。
毕业条件：vs Greedy 胜率 > 70%。

### Stage 2：元素反应

```
场景：1v1 异角色对战（所有 C(5,2)=10 种对局）
卡牌：L1 + L2
对手：贪心 → 自博弈（初级）
```
目标：利用元素反应提高伤害。
毕业条件：vs Greedy 胜率 > 80%。

### Stage 3：追踪型卡牌

```
场景：1v1 全角色对战
卡牌：L1 ~ L3
对手：自博弈
```
目标：学会跨步生效的卡牌。
毕业条件：观察到 L3 卡牌合理使用。

### Stage 4：系统联动卡牌

```
场景：1v1 全角色对战
卡牌：L1 ~ L4
对手：自博弈（策略池）
```
目标：学会切换、能量传递、召唤物克制相关卡牌。
毕业条件：观察到系统级策略。

### Stage 5：角色专属卡 + 1v1 平衡性

```
场景：1v1 全角色对战
卡牌：L1 ~ L5
对手：自博弈（策略池 + Elo）
```
目标：学会专属卡，评估 1v1 平衡性。
毕业条件：各角色综合胜率极差 < 20%（验收标准 4）。

### Stage 6：全局策略卡

```
场景：1v1 全角色对战
卡牌：L1 ~ L6
对手：自博弈（策略池 + Elo）
```
目标：学会全局策略流派卡。
毕业条件：稳定自博弈收敛，完成牌分数评估（验收标准 6）。

### Stage 7：多角色阵容

```
场景：2v2 全阵容对战（C(5,2)=10 种阵容）
卡牌：L1 ~ L6
对手：自博弈
```
目标：多角色管理。
毕业条件：完成最强阵容分析（验收标准 5）。

迁移策略：Instruction Encoder 保持冻结，State Encoder + Grounding 复用，Action/Value Head 重新初始化，学习率减半。

### Stage 8：平衡策略适应

```
场景：2v2 + 随机平衡 patch（1~4 个）
卡牌：L1 ~ L6
对手：自博弈
```
目标：适应 patch 组合。
毕业条件：验收标准 7、8。

## 4. 完整训练流程

```
预训练（Instruction Encoder）：
P1 --> P2 --> P3
单步     复杂    多步+价值
L1-L2   L1-L4   L1-L6
         | 冻结 Instruction Encoder

RL 课程（Grounding + Policy/Value）：
Stage 0 -> 1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8
基础     技能  反应  L3牌  L4牌  专属卡  策略卡  2v2  patch
Random  Greedy  自博弈 ----------------------------------------
-------------- 1v1 --------------------------  -- 2v2 ------
```

## 5. RL 阶段辅助损失

RL 训练期间保留单步 counter 预测作为辅助损失，维持 DSL 理解能力：

```
total_loss = policy_loss + 0.5 * value_loss + 0.01 * entropy_bonus + 0.1 * aux_prediction_loss
```

`aux_prediction_loss`：用当前观测和执行的动作，预测 counter 变化量。

## 6. 阶段间衔接

- 网络权重热启动（继承上阶段，Instruction Encoder 始终冻结）
- 新增的 counter/hook 槽位初始化为零
- 学习率按余弦退火调度，阶段切换时重置
- 每阶段独立的策略池（旧阶段策略池不兼容）

## 7. 算法配置

```
算法：PPO + GAE + 动作掩码
框架：自实现（轻量级，便于自定义两步决策和自博弈）

超参数（初始值，后续按阶段微调）：
  学习率：3e-4（Grounding + Policy/Value），1e-6（Instruction Encoder，如不冻结）
  GAE lambda：0.95
  PPO clip：0.2
  Entropy bonus：0.01（前期鼓励探索）→ 0.001（后期收敛）
  Batch size：2048 steps
  Epochs per update：4
  Discount gamma：0.99
  并行环境数：64（Go 引擎多实例）

自博弈配置：
  策略池大小上限：30
  对手采样：70% 最新 self，20% 随机历史，10% 贪心/随机基线
  Elo 评分更新：每 500 局
  Checkpoint 间隔：每 5000 局
```

## 8. 奖励设计

```
训练奖励（含 shaping）：
  终局：胜 +1，负 -1，平 0
  击杀敌方角色：+0.05
  己方角色被击杀：-0.05
  每回合存活奖励：+0.005（鼓励不拖局）

  shaping 随阶段衰减：
    Stage 0-2：shaping 系数 1.0
    Stage 3-6：shaping 系数 0.5
    Stage 7-8：shaping 系数 0.1

评估奖励（严格）：
  仅胜负：+1 / -1 / 0
```

## 9. 关键风险与对策

| 风险 | 对策 |
|------|------|
| Instruction Encoder 预训练不充分 | P3 用全量 DSL 训练，验证预测准确率 > 90% |
| RL 阶段 DSL 理解退化 | 辅助损失 0.1 权重持续维持 |
| 策略循环（A克B克C克A） | 策略池 + 优先对弱势对手训练（PFSP 思路） |
| 新阶段知识遗忘旧技能 | 混入 10% 旧对手（贪心/随机）保持基础能力 |
| 某角色/卡牌过强致单一策略 | 监控角色使用率和胜率分布，必要时调数值 |
| 2v2 动作空间过大 | 切换决策单独建模为子策略，或限制切换频率 |
| Shuffle 致学习过慢 | 前期（Stage 0-1）可半 shuffle，逐步引入全 shuffle |
| 平衡 patch 组合爆炸 | 每局仅采样少量 patch，不枚举全部组合 |
