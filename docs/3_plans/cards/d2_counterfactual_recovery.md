# D2 反事实恢复路线

状态：native DMC recovery 主路线；opening teacher 未取得资格，reroll adapter 训练暂停。重骰教师仅保留有限预算的资格验证，后续若通过再接入联合改进。

## 目标

先让新增重骰阶段通过终局结果学会可验证的决策，同时结构性保护 RL16 的普通动作能力；完成恢复后，再允许普通策略继续学习并挑战 F1-D2。

不使用手工重骰标签、局部骰子奖励、D2 代替学习方重骰或运行时规则兜底。

## P0：环境与模型契约

训练开始前必须完成：

1. 同状态 Q→policy 行为等价审计。
2. 合法动作顺序、mask 和动作容量审计；超过容量必须报错，不允许截断。
3. 价值所属玩家、连续行动权、快速行动和终局符号测试。
4. 重骰 chance 分布、克隆 RNG 和双方重骰后回合开始效果顺序测试。
5. 固定玩家信息状态、改变真实隐藏世界后的根决策不变性测试。
6. 续局策略、对手分布和 value 目标的一致性检查。

当前结果：

- 旧 RL16→AZ 转换未通过。转换只复制通用 `base` 参数，AZ 前向没有保留语义图关系计算。4 局 823 个状态中，普通决策 argmax 一致率 71%，最大概率误差 0.608。因此转换产物不得作为等价 RL16 基线或新训练起点。
- 动作容量路径会在 `n_legal > max_actions` 时显式报错，不会静默截断；当前 4 局样本最大合法动作数为 98，扩大覆盖仍待完成。
- Python 与 Go MCTS 都把价值统一存为 P0 视角，选择时按当前行动方翻转；连续同一玩家动作不会机械反号。
- 快照精确保留 RNG，搜索在私有模拟中显式设置 simulation seed；双方先掷骰、完成重骰后再触发回合开始效果已有引擎测试。
- 当前 MCTS 没有独立 chance 节点。不同随机结果共享同一动作历史节点，并复用首次展开的 prior/value；因此现有搜索教师不具备扩训资格。
- 通用 matchup 搜索会从当前状态的 `hand_refs + deck_refs` 构造剩余牌表。公开牌表协议必须成为显式输入，不能依赖读取真实状态来推断本应未知的信息。
- 反事实续局已重采样己方未来牌序、对手手牌/牌库划分，以及先手重骰根中尚未重骰的对手骰面。后手根需要对手已执行重骰后的骰面后验，当前资格评估因此只使用先手根。

## C：隔离重骰学习

### 动作单位

引擎当前按颜色依次选择重骰数量。训练侧把一次完整重骰流程表示为一个宏动作：八种颜色各自的重骰数量向量。运行时仍按现有协议逐步提交，不修改规则语义。

候选覆盖：

- 当前 RL16 形成的完整选择；
- 模型评分靠前的其他完整选择；
- 覆盖性的随机合法选择；
- 零重骰和全重骰等边界选择。

不把每颗骰子独立分类，也不只采旧模型 top-k。

### 标签

冻结 RL16 普通续局策略和固定对手分布。对同一可见根状态的每个候选宏动作执行完整终局续局：

`Q_reroll(I, a) = E[z | I, a, frozen RL16, frozen opponent]`

候选选择样本与收益验证样本使用不同随机种子。第一阶段只用真实终局结果；冻结 value 只有在后继状态校准和分支排序均通过后，才能用于扩充标签。

### 网络与保护

- 原 SemanticQNet 的普通动作路径全部冻结。
- 新增独立 reroll Q adapter，读取冻结语义状态、骰子数量向量、阶段信息和完整候选向量。
- 普通状态的原始 logits 必须逐项不变，作为自动门禁。
- 暂不训练 AZ value/delta，也不使用 KL 代替冻结保证。

### 最小教师实验

- 16–32 个独立重骰根状态。
- 每根比较当前动作与 1–3 个候选；判断不清的根再追加预算。
- 报告独立根状态数、每候选续局数、终局步数、前向次数、墙钟和配对收益区间。
- 只有独立验证中的配对收益为正，才训练 reroll adapter。

### 资格结果

2026-09-22 完成 32 个先手重骰根的正式筛选。每根包含 6 个候选、8 次候选发现和 12 次独立验证；隐藏牌序、对手手牌/牌库划分和对手未重骰骰面均按玩家信息状态重新采样。

- 平均根配对收益 -0.0104；根状态聚类正态 95% 区间 [-0.0933, +0.0725]；
- 7 个正收益根、13 个零收益根、12 个负收益根；
- 384 个验证配对中正差 40、负差 42、零差 302；
- 候选发现与验证共消耗 486,840 个环境步、237,134 次学习方网络前向。

预算达到预定的 32 根上限后区间仍跨零，当前直接反事实教师暂停。随后对 4 个先手根枚举完整合法重骰向量，其中 2 个根产生非 current raw leader，另 2 个根的 leader 为 current。对两个 raw leader 各做 64 次独立 paired validation：aligned 均值为 +0.0625、-0.21875，聚合为 -0.0781，根均值 95% 区间 [-0.3538, +0.1975]；unaligned 均值为 +0.03125、-0.03125，聚合为 0，区间 [-0.0613, +0.0613]。两种设置均无 qualified root。

opening teacher 尚未取得资格，但该复验只有两个非 current 根，不能全局否定反事实重骰学习方法。不得训练 reroll adapter，也不得恢复 ExIt；主线转为 native DMC recovery。若重启教师，必须扩大非 current 根覆盖，解决候选选择方差与后手隐藏骰面后验，并在全新根状态与验证种子上重新取得资格。

### 终局 PG 与动作级成对反事实补充

终局 PG 在训练 seed 932000、932100、932200、932300 上相对 acceptance 基线分别为 `+3.636pp`、`-1.818pp`、`-0.455pp`、`+3.182pp`；均值 `+1.136pp`，two-level CI 跨零，暂不具备晋级证据。

四个单步 checkpoint 的等权 soup 在新 seed 935000 上为 `38.636%`，RL16 基线为 `41.364%`，paired delta `-2.727pp`，paired 95% 区间 `[-6.818pp, +0.909pp]`。

generic pair 的 256 局 × 4 repeats 开发分数为 `30.0%`，基线为 `31.818%`。其 reroll 根实际比较的是逐色内部选择，且不同分支的重骰数量会造成后续 RNG 错位，因此不构成完整宏动作教师。改为 ordinary-only、128 局 × 8 repeats 后开发分数仍为 `30.0%`，仅产生 31 条 rows，其中 17 条权重为 `0.25`、14 条出现 discordance，说明终局动作偏好仍过于稀疏。

原语顺序、观察和动作编码已通过契约测试；当前问题集中在教师标签构造和方差，不能判定教师方法整体失效。暂停扩训。后续只考虑完整 macro reroll 或已校准 value 降方差路径，且必须先通过独立资格验证。

## A：语义 DMC 恢复与联合改进

C 通过后，以修复后的 checkpoint 为参考点恢复终局 Monte-Carlo 学习：

- replay 显式记录决策类型、环境版本、对手版本和数据年龄；
- 初始关闭 PER，按类型分层抽样，重骰约占三分之一作为实验起点；
- 先解冻 reroll adapter，再解冻共享交互层，最后才考虑规则编码器；
- 每次解冻同时检查固定普通状态面板、当前规则 F1-D2 和 heldout 规则；
- 旧环境终局标签不混入当前规则 replay。

联合改进的对照不是旧的 36.8%，而是 C 阶段完成后的新环境恢复基线。

## 实验关口

| 阶段 | Go | No-go |
|---|---|---|
| P0 契约 | 所有正确性测试通过 | 任一动作错位、符号、随机性或信息泄漏问题 |
| 反事实教师 | 独立验证的根聚类 95% 区间下界高于零 | 32 根预算耗尽后区间跨零则暂停；上界不高于零则否决 |
| C 隔离学习 | 重骰收益提升且普通 logits 不变 | 只有行为表象变化，或普通能力发生漂移 |
| A 恢复 | 多 seed 优于未修复参考且 heldout 不崩 | 明显遗忘或仅单 seed 偶然收益 |
| 超过 D2 | 多训练 seed、独立测试 seed、场景聚类 95% CI 下界 >50% | 仅点估计超过 50% |

64 局只用于发现明显退化、塌缩和工程错误，不用于判断小幅配方优劣。
