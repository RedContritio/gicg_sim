# 逐卡价值：胜率贡献与出牌时机

2026-09-13。用户希望直观、量化、可计算地判断每张卡牌价值，不要求绝对精确。本文记录已提出的方案；全牌测量尚未实现或执行。当前训练、独立强度验收和早期L6案例观察继续按原协议进行。

## 两个核心指标

### 两卡位构筑价值

同一合法阵容下，构造两个30张牌组：A含两张目标牌C与固定28张其他牌；B保持这28张不变，把C替换为两张合法替代牌。固定28张不含C；两个牌组每种最多两张。替代牌从该阵容引擎判定的剩余合法副本中无放回抽取，不手写天赋/武器规则。多组替代避免只测出“比某一张烂牌强”。

指标：`V_deck(C) = 胜率(A) - 胜率(B)`，单位为百分点。它衡量两卡位相对随机合法替代的贡献，不能直接除以二解释成单张价值。角色生成牌不属于起始构筑干预全集。

配对固定己方阵容、对方阵容与牌组、物理随机种子，交换席位。除指定两个替代位置外，其他卡的洗牌后相对位置必须核验一致，不能仅凭“传入相同种子”断言配对成立。双方策略相同，均可观察自己实际手牌并适应；不向策略泄露对照组信息。

天赋和武器只在合法阵容测量，结果标注条件覆盖。总体按预先规定的合法阵容权重汇总，并提供按阵容拆分。没有足够合法替代容量时显式拒绝该构筑，不能缩成不足30张。

### 当前出牌价值

从真实对局中“C在手且至少一种使用方式合法”的状态抽样，不要求模型实际选择C，更不能要求原局获胜。

- A：模型评分最高的合法C出牌动作（包括目标/支付选择）。
- B：模型评分最高的其他动作，排除所有直接打出C的动作，避免另一份C或另一目标成为伪对照。
- 后续策略相同、每组未来随机种子配对；B允许之后再打C。

指标：`V_play(C, s) = P(赢 | 此刻打C, s) - P(赢 | 此刻最佳其他动作, s)`。按第1回合、第2–3回合、后期分层汇总。它回答现在打还是稍后考虑，不能解释成从整局永久删除C的价值。

状态采用按对局/卡牌/时段限额的随机蓄水池抽样，记录纳入概率或预设均衡权重，避免冗长对局与反复未出牌状态主导报告。目标牌没有合法使用方式时不伪造出牌分支，而记为不可用机会。

## 统计与呈现

每张牌展示：

| 字段 | 含义 |
|---|---|
| 两卡位胜率贡献 | 相对多组随机合法替代的百分点差 |
| 首回合/中期/后期出牌价值 | 对应合法状态样本中的单动作优势 |
| 适用阵容与对手 | 哪些条件下成立；D2主标准、D1基础检查 |
| 覆盖 | 入组、见过、可用、使用的对局数及有效独立场景数 |
| 不确定性 | 配对场景聚类区间，不能把布局副本或同状态续局当独立场景 |

同时输出逐场景差值及原始干预信息供复核。全部卡牌统一呈现；排名接近或区间重叠时不强行排出高低。跨多张牌寻找最高分有选择偏差，追加预算采用新场景，不能只累计有利样本。

不强行将伤害、治疗、护盾、骰子换算成单一“经济分”。这些只用于解释实际收益路径，且必须区分请求治疗/有效治疗、护盾吸收/浪费、减费额度/实际省骰等。

## 当前模型价值与卡牌潜力

所有数值绑定冻结的模型SHA、规则指纹、卡池、阵容分布、对手与种子。测到的是该策略能发挥的价值，不是卡牌理论上限。模型换代后可用同口径重新测量。

可对D2执行同样的构筑和状态分支测量，比较模型与D2利用卡牌的差异。要归因于RL，还需比较对应监督起点；仅凭RL模型打出了D2没出的牌不成立。

现有 `early_l6.py` 是先筛选早期出牌胜局再做条件对照的探索工具，不符合全牌价值的无偏状态抽样要求，不可直接拿其结果填这张价值表。其乘胜例子有条件收益证据，而以逸的原始胜局几乎没有单动作增益；详 `docs/5_history/early_l6_initial.md`。

## 实施顺序

1. 先实现配对合法构筑与洗牌位置核验，以及全部合法出牌机会的采样器。
2. 在56用小预算验证构筑、原状态恢复、配对随机事件、行动选择和不确定性计算。
3. 冻结目标模型后粗测全部26种原牌；计算预算与主验收分开，不中途改变训练策略。
4. 再给区间宽、阵容差异大或有明显延迟收益迹象的牌追加独立样本。
5. 输出易读表格、按阵容/时段拆分和代表性回放，同时保留负面与无显著收益结果。
