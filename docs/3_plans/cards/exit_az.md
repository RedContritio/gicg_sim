# ExIt / AZ 固定对手支线

状态：暂停。端到端 ExIt 不再是当前主路线。

## 已有结论

- 从零 ExIt、无锚 RL16 热启动和 beta=0.3 锚定训练都未超过原 RL16。
- run `202609200935_000084_exit_ws_anchor_b1` 只有 12 局、797 条 transition、32 次训练更新，不是可判读的 beta=1.0 实验。
- 旧 RL16 到 AZ 的转换不是行为等价转换。4 局 823 个同状态决策审计中，普通决策 argmax 一致率为 71%，最大概率误差为 0.608。
- 当前 8-rollout 搜索从未在冻结策略上独立证明正向 teacher gain。

## 恢复条件

只有同时满足以下条件，ExIt 才能重新进入训练闭环：

1. 价值视角、连续行动权、随机节点、RNG 克隆、determinization 和隐藏信息隔离的契约测试全部通过。
2. 搜索直接作用于原语义网络，或新的转换在同状态、同合法动作集合上通过行为等价测试。
3. 冻结策略上的搜索动作在独立续局样本中，相对原 argmax 具有正向配对收益。
4. 搜索目标离线蒸馏后，argmax 策略在独立样本中仍有正向收益。

恢复后先做固定根状态的教师验证，不直接恢复在线端到端训练。锚定强度只在教师已经通过验证后讨论。

## 保留资产

- 固定对手收集、Go MCTS、异步多进程 actor 和本地推理链路继续保留。
- `anchor_exclude_reroll` 保留为通用实验能力，不代表当前获准配方。
- 历史配置和结果继续保存在版本历史及 `docs/5_history/` 中。
