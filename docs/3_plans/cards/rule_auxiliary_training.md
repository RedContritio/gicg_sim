# 规则辅助任务与 RL 联合训练

当前目标仍是随机规则变体下稳定胜过 D2，不能用辅助预测准确率代替对战验收。

## 动机与已知证据

随机变体 RL 的独立胜率约39–43%；两轮 DAgger 路径均退步。凯亚3v3配对交换伤害2/6、4/8时仍固定偏好霜袭。规则小课单独可学，但后续BC遗忘。现在改为持续提供引擎结算监督，与整局RL共同训练。

## 实施顺序

1. 已实现 `semantic_training.rule_outcomes`：snapshot/step/restore得到当前行动方视角的自身/敌方总HP变化、总能量变化、存活数量变化、终局标志、终局结果、pending标志。9个字段描述一次env.step后的真实结果，pending不当成完整结算。6测试覆盖五角色、快照恢复、伤害交换；不预言长期价值。
2. 在真实随机变体对局的部分决策采集动作及备选技能/卡牌结算。标签由实际引擎生成，不从名称或静态伤害字段猜测；保留变体manifest和场景种子。需要覆盖治疗发生、反应、减费、延迟效果触发等实际机会，初始HP全满不足以验证治疗。控制分支数量并量化额外采样耗时。
3. 网络暴露共享状态/动作表示，新增训练用结算预测头。辅助梯度进入共享规则与动作编码；终局价值基线原有梯度隔离保持。即时结算标签不直接强制动作优劣，长期选择仍由RL回报决定。checkpoint保存辅助头、优化器、采样与损失配置及来源；恢复必须校验，不重标旧权重。
4. 先小规模GPU冒烟验证辅助头/共享编码梯度、RL采样概率一致性、恢复连续性。再从已兼容RL起点做同预算联合/无辅助对照。开发种子与最终冻结种子分开；实际预算启动前固定落盘。
5. 三条证据同时报告：未见变体结算预测误差；五角色配对规则改变后的策略响应（即时排名仅在有明确可比较意义的场景要求）；独立3v3随机合法30张对D2胜率。反事实模型预测正确但策略不响应仍未解决目标。

最终仍须三独立训练种子、冻结随机变体测试以及场景聚类置信下界高于50%的既有验收。步骤1–4已完成实现与一轮对照，尚未证明强度收益。
