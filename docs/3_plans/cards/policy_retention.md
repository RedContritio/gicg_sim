2026-09-16。同一监督预热与配对规则训练流程的六臂对照，以及一个独立的隔离臂复核。
目标是找出一套初始化：
规则预测继续改善，同时不把预热策略在配对训练阶段打坏，供后续RL使用。这里只验证
初始化质量，不把任何单臂结果当作已经稳定胜过D2。

## 问题

同一96400确认面板、每模型440局，监督预热模型得分34.55%；经过配对规则学习的初始
模型得分19.09%。配对差值为-15.45个百分点，场景聚类95%区间
[-22.73,-7.73]个百分点。退化发生在预热到配对模型的阶段，但只有一个初始化和一次
训练轨迹，不能据此断言规则监督必然损害策略，也不能把预测改善与策略退化混成一个指标。

本实验固定同一份预热检查点、同一批配对数据、同样的1500次更新和同一训练seed，
只改变保留机制。现有3步smoke只提供机制方向：`frozen`逐元素零漂移，学习率相关的
漂移按比例变化，`anchored`门控实际触发过；smoke没有面板胜率和探针，不作为效果结论。

## 六臂

| 臂 | 训练范围与机制 | 要区分的问题 |
|---|---|---|
| `full` | 全部可训练策略参数与规则头，lr `3e-4` | 复现配对回归造成的策略损害 |
| `frozen` | 冻结策略网络，只训规则头 | 预测学习是否必须改动共享策略 |
| `probe_then_finetune` | 前750步冻结策略，后750步全参数微调，lr `3e-5` | 先拟合规则头再小步适配是否足够 |
| `full_lowlr` | 全参数，lr `3e-5` | 把学习率效应与保留机制分开 |
| `replay` | 配对回归加D2模仿loss，权重1.0 | 原任务 rehearsal 是否保住策略 |
| `anchored` | 配对回归加warmup前向KL，β=1.0；共享策略梯度按D2模仿梯度的余弦符号二元门控 | 锚点与冲突门控能否限制漂移 |

所有臂使用同一随机初始化、同一teacher样本和同一配对batch顺序。规则头训练不受二元
门控影响；门控只取消共享策略上的配对回归梯度。

正式六臂结束后追加执行 `isolated_rule`：冻结Q分支，在零初始化残差adapter上训练规则头。
该臂只用于确认“消除共享Q漂移”是否足以保留规则学习，不进入选臂面板。结果是Q零漂移但
`states/values/train`变化方向准确率均未改善，明确否决；详细终值见历史报告。

```bash
python -m tools.experiments.semantic_training.policy_retention \
  configs/dmc/policy_retention.toml <warmup>/ckpts/latest.pt <out>/retention \
  --teacher <warmup>/teacher \
  --steps 1500 --contexts 6 --teacher-rows 2048 --workers 16 \
  --seed 95000 --device cuda \
```

不能重建后把不同数据混入同一对照。每臂产出：

- `report.json`：初始、probe退出点和最终配对评估，含MAE、变化方向准确率、CKA、
  参数漂移、余弦门控与拦截次数。
- `<arm>_policy.pt`：可交给现有评估器和RL入口的策略检查点。
- `<arm>_panel/result.json`、`<arm>_probe.json`：确认面板和凯亚反事实探针。

### 确认面板

- 110场景 × 双方席位 × 2布局 = 每模型440局。
- 新seed `96600`；`96400`已被用于选模，`96500`已用于一次规则头起点不一致而作废的
  六臂运行，两者都不能继续充当独立证据。
- 对D2对手depth 2，使用同一held-out variant catalog和同一物理场景配对。
- 除各臂相对warmup的差值外，还必须直接报告臂对臂的场景聚类95%区间，不能只列各臂
  各自相对warmup的成绩。

## 判断规则

先检查机制是否按定义执行：

1. `frozen`策略参数必须逐元素不变，规则头必须发生变化。
2. `probe_then_finetune`必须记录probe退出点，不能把冻结期效果写成全参数微调结果。
3. `anchored`若无门控触发，只能视为“KL锚点臂”，不能声称验证了冲突门控。
4. 任一臂出现非有限loss、梯度或输出时立即淘汰，不继续补预算。

再检查规则学习：

- 主判据是`states`和`values`两个留出划分的MAE、变化方向准确率和
  `delta_within_half`，同时看`train`确认不是只拟合训练参数。
- 预测改善只在`values`至少不退化为随机头时，才可进入策略比较。单看训练MAE下降
  或探针预测`16/16`都不够。

最后检查策略保留：

- 主结果使用440局面板得分、双方席位、超时/击倒构成和配对区间。`frozen`的零漂移
  只是机制证据，不能代替胜率。
- 某臂点估计低于warmup且与warmup的配对区间完全落在0以下，记为明确退化；区间跨0
  时记为未决，不写成收益或损害。臂之间的取舍优先看直接配对区间，而不是各自区间的
  视觉重叠。
- 只有一个臂同时满足“规则留出改善”和“对warmup没有明确退化”，才直接晋级为下一轮
  RL起点。多个臂都满足时，选择臂对臂配对证据更稳且机制更简单的一个。
- 没有臂同时满足两项时，不扩大RL预算；先分解回归目标、共享编码器梯度和规则头容量，
  再设计新的隔离实验。不能改低面板或探针标准来宣布某臂成功。

## 范围与后续

本实验只有一份预热、一个配对数据seed和一个训练seed，只能判断当前配置下哪种保留
机制值得进入下一步，不构成G3强度结论，也不证明对全部规则或官方完整规则泛化。
96600一旦用于选臂，后续晋级必须换新的独立seed。

通过后，用选中的策略检查点进入等预算RL；同时保留`full`和warmup作为损害复现与
策略保留对照。完成后在`docs/5_history/`记录原始运行、当前指纹下的一次性结果、
选择依据和未决项；本卡保留为协议与恢复入口，不把计划文案当作结果报告。

`isolated_rule` 已结束，不继续扩展同容量control；报告中保留“独立路径收益与容量因素
未严格分离”的限制，不把它写成有效解决方案。
