# 项目版本约定

项目当前版本由根目录 `VERSION` 唯一指定，格式为 `vA.B.C`，当前为 `v0.3.0`。
项目仍处于实验开发阶段；语义版本系列从 v0.1.0 起，不用阶段编号表达版本。

- A（主版本）：不兼容的规则、观测、动作或公共接口变更。
- B（次版本）：兼容的新能力、新原语或新增评估能力。
- C（修订版本）：兼容的缺陷修复、行为等价重构和文档修正。

零主版本仍遵循上述递增含义；破坏兼容时明确升级主版本，不将其藏在修订版本内。
下一级递增时低位归零，例如 v0.1.9 → v0.2.0；普通提交不必递增版本。
每次可复现的验收/发布基线确定版本，不为每个任务或工具另造递增的阶段版本。

OpenSpec change 目录采用稳定的职责名称，例如 `submission-refactor`；
版本写入 VERSION、验收和来源清单。实验种子、运行 ID、预算和文件格式 schema
分别保留各自用途，不与项目版本混用。来源哈希继续决定检查点能否严格加载，
版本号相同或仅增加修订位都不能替代来源校验。
