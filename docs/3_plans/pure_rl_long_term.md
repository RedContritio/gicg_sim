# 长期方向：从零开始的纯强化学习

2026-09-13，用户明确希望长期追求类似AlphaZero的纯RL训练路线。当前全L1–L6课程继续完成，作为环境、评估与BC+RL性能基准；本文不表示现在中断主训练，也不表示纯RL已实现或验证。

## 研究目标与“纯”的定义

- 新模型随机初始化，不加载专家示范、BC权重或由这些权重产生的训练经验。
- 主线训练数据来自自己的对弈与历史自我版本；D1/D2作为外部评估对手，不提供训练动作标签或启发式价值目标。
- 以终局胜负作为主奖励。保留准确规则、合法动作与支付、公开规则语义等任务定义；不把手写卡牌好坏或战术评分包装成终局学习。
- 允许网络引导的搜索产生自我改进目标。拟合自己搜索出的动作分布仍可属于该路线，不等同于使用外部专家示范。
- 当前BC+RL权重可作为冻结对照对手与独立评估对象；严格主线不从其动作、logit、回放或梯度中训练。

AlphaZero从随机策略通过自我对弈训练，并结合神经网络与搜索；“不使用专家示范”不等于“没有规则、没有结构归纳偏置、没有搜索”。来源：[DeepMind原始介绍](https://deepmind.google/blog/alphazero-shedding-new-light-on-chess-shogi-and-go/)、[原论文](https://doi.org/10.1126/science.aar6404)。

## 适配七圣召唤的关键问题

棋类AlphaZero的成功不能直接证明本项目必定成功。这里有隐藏手牌、隐藏骰子与随机抽牌等信息约束；搜索不能直接读取真实隐藏状态替模型选动作。必须定义信息集或信念采样，并验证对手决策没有偷看本不该知道的信息。

终局反馈稀疏、无效消耗与调和/换人循环、联合动作空间大、自我对弈共同退化、长期卡牌投资难探索，都需要分别诊断。先验证实现与实际学习信号，再判断预算或算法是否不足；不将单个种子失败判为路线不可能。

## 分阶段推进

1. 完成当前可靠环境、全池独立D1/D2评估及案例/覆盖审计，冻结代码与比较基准。
2. 审查现有AZ相关代码的梯度路径、规则编码训练、快照/恢复、信息边界、搜索目标、训练/推理一致性；通过真实端到端验证后才复用组件，不继承旧污染产物。
3. 从随机初始化在小任务验证纯自我对弈是否学会合法有效行动，至少多个训练种子。先建立不带搜索的纯RL基线，便于分辨搜索本身的贡献。
4. 加入合规的网络引导搜索、历史自我对手池与探索机制；记录每步搜索和环境对局的真实算力成本。
5. 逐步扩展到五角色随机2v2、完整L1–L6、固定30张随机合法牌组，不用永久移除难牌换取成功。
6. 全池新场景/构筑/席位独立测试，对D1、D2及冻结BC+RL基准；同时报告纯NN推理和带搜索推理的成绩与耗时，避免把搜索算力当成网络自身能力。
7. 达到稳健强度后再做未见卡牌与规则组合适应，分别报告零样本、允许少量微调和新增原语的条件。

## 比较与验收原则

比较BC+RL和纯RL时同时列出对局数、环境步数、搜索模拟数、CPU/GPU小时、峰值内存与推理延迟。相同训练轮数不代表相同预算。

冻结选模协议，开发与最终测试分离，多个独立初始化。布局复制不增加有效样本数；按物理场景和训练种子报告不确定性。最终强度目标仍是完整池稳定胜D1并对D2有优势。

用逐卡价值与早期L6投资案例作为行为证据，关注能否发掘D2未利用的长期收益；不以少数漂亮胜局替代总体强度或因果验证。

大规模采样、搜索、训练与评估都优先放在56设备。具体算法、搜索预算与正式训练时长留待前置基线完成后决定，不预承诺AlphaZero式结果或收敛时间。
