## 设计理念

本项目采用**分层架构**设计：

1. **核心层（core/）**：纯游戏逻辑，无外部依赖
2. **接口层（env/, gui/, ai/）**：为不同用途提供接口
3. **应用层**：RL 训练、GUI 界面等实际应用

这种设计保证了：
- **可测试性**：核心逻辑可以独立测试
- **可扩展性**：易于添加新接口和新功能
- **可维护性**：关注点分离，代码清晰
